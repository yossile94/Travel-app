# רשימת משימות לפני בטא והשקה

כל מה שנדחה בכוונה ל"לפני הבטא" או ל"לפני ההשקה" נרשם כאן, עם הסיבה, כדי שלא יישכח. ג'ון מזכיר ליוסי את הרשימה בתכנון ספרינט 10 (Hardening).

## לפני הבטא

- [x] **להחליף את מפתח הפיתוח של Mapbox** (2026-10-23): נוצר מפתח `travel-app-dev` עם הרשאות מינימליות (STYLES:TILES, STYLES:READ, FONTS:READ), ועודכן ב-`.env.local` וב-Expo. **הסיבה:** המפתח הקודם נשלח בצ'אט ב-2026-10-22.
- [ ] **למחוק את מפתח Mapbox הישן** בדף Tokens, אם עוד לא נמחק או הוחלף ב-Rotate.
- [ ] **מפתח Mapbox נפרד ל-production** (`travel-app-prod`), עם אותן הרשאות, רק בסביבת production ב-Expo. מעקב אחרי השימוש בדף Statistics כדי לזהות שימוש לרעה במפתח.
- [x] **כרטיס אשראי ב-Mapbox** (2026-10-23): החשבון עבר לתמחור pay-as-you-go עם המכסות החינמיות (25,000 משתמשים בחודש לנייד ו-750,000 בקשות לוויין). תמונת הלוויין נטענת, בלי שגיאות 429.
- [ ] **מחיקת חשבון גם למשתמשי Apple:** ה-Edge Function `delete-account` מאמתת מחדש רק עם Google. לפני ההשקה ב-iOS צריך גם אימות מחדש עם Apple (ADR-006 סעיף 6).
- [ ] **נורמות של אילת ממקור רשמי:** היום הערכים לקוחים מ-climieviaggi.it, מקור משני (ADR-007). צריך להחליף אותם בנתוני השירות המטאורולוגי, לבדוק את תנאי השימוש שלו, ולהוסיף אותו לגיליון "מקורות". צריך להוסיף אותו גם למחרוזות `sources.*` בעברית ובאנגלית (רז).
- [ ] **חלון קצר לאימות מחדש במחיקה:** היום השרת מקבל כל ID token של Google שלא פג (60 דקות, B-1). לפני production לבדוק Credential Manager עם nonce, ולחזור לחלון של כמה דקות (ADR-006 סעיף 6).
- [ ] **`CRON_SECRET` ל-rates-daily ול-advisories-daily** (ADR-008, דודי D1): יוסי יוצר סוד, ושם אותו ב-secrets של הפונקציות וב-Vault. הפונקציות בודקות אותו בזמן קבוע.
- [ ] **הגבלת קצב ל-`delete-account`** לפי משתמש, לפני production (ADR-006 סעיף 6).
- [ ] **חשבון Apple Developer** (99$ לשנה): לפתוח אותו, להפעיל את ההתחברות עם Apple שמוסתרת מאחורי feature flag, ולבדוק את כל האפליקציה על iPhone (ראו CHANGELOG באפיון, 2026-10-21).
- [ ] **סביבת prod ב-Supabase** בתוכנית Pro.
- [ ] **גרסה 1 של תנאי השימוש ומדיניות הפרטיות פורסמה** ב-`legal_documents` לפני שפותחים את production. **בדיקה:** `select 1 from public.current_legal_documents where version = 0` לא מחזירה שורות. גרסה 0 היא טיוטה שלא נבדקה (ADR-004).
- [ ] **מדיניות פרטיות: העותק במכשיר** (ADR-009). עותק מוצפן של הנסיעות נשמר במכשיר כדי להציג אותן בלי רשת, ונמחק בהתנתקות ובמחיקת החשבון.
- [ ] **רשימת סטטוס כניסה בדרכון ישראלי** (ספרינט 4, AC-6). הנתונים מוזנים ידנית, עם מקור ותאריך אימות לכל יעד. לא נמצאה רשימה רשמית, ולכן הטבלה ריקה עד שתאומת.
- [ ] **מסמכים משפטיים:** מדיניות פרטיות, תנאי שימוש ומסמך הגדרות מאגר, אחרי עו"ד.
  - מספרינט 3 נשמרים שמות של נוסעים נלווים ללא חשבון, כולל קטינים (`relation='child'`). המדיניות והגדרות המאגר צריכות לציין זאת במפורש (סקירת דודי, ספרינט 3; ראו גם 04-auth-and-regulation).
- [ ] **דף מחיקת חשבון באינטרנט** (דרישת Google Play בטופס Data safety, לפני Closed Testing): דף שבו משתמש מבקש למחוק את החשבון גם בלי האפליקציה. נדחה מספרינט 2.

## לפני ההשקה

- [ ] **שם האפליקציה ומזהה החבילה:** להחליף את הערכים הזמניים (`Travel App`, `com.travelapp.companion`). אי אפשר לשנות את מזהה החבילה אחרי ההעלאה הראשונה ל-Google Play.
- [ ] **node-forge:** לבדוק שיש גרסה מתוקנת לפני שמפעילים חתימה על עדכוני OTA (ראו [dependency-audit.md](../security/dependency-audit.md)).
- [ ] **בדיקת חדירות חיצונית**, כולל זרימת הדרכון (אפיון 6.3).
- [ ] **טיסות (ספרינט 5):** במדיניות הפרטיות כותבים שקוד ההזמנה (PNR) והמושב נשמרים עד שהנסיעה או החשבון נמחקים, ושהם לא נשלחים לספק. מפרקים את שער הכיסוי לפני production: `flight_coverage_probes`, ה-cron שלו והפונקציה `flight-coverage`. ב-production מוחלפים `cron_secret` ומפתח AeroDataBox (דודי).
