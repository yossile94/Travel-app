# רשימת משימות לפני בטא והשקה

כל מה שנדחה בכוונה ל"לפני הבטא" או ל"לפני ההשקה" נרשם כאן, עם הסיבה, כדי שלא יישכח. ג'ון מזכיר ליוסי את הרשימה בתכנון ספרינט 10 (Hardening).

## לפני הבטא

- [ ] **להחליף את מפתח Mapbox:** ליצור מפתח ציבורי חדש ב-Mapbox, לעדכן אותו ב-`.env.local` ובמשתני הסביבה של Expo, ולמחוק את המפתח הנוכחי. **הסיבה:** המפתח הנוכחי נשלח בצ'אט ב-2026-10-22.
- [ ] **כרטיס אשראי ב-Mapbox:** בלי כרטיס החשבון מוגבל ל-100 משתמשים בחודש. עם כרטיס המכסה החינמית היא 25,000 משתמשים בחודש (ראו [accounts.md](../setup/accounts.md)).
- [ ] **חשבון Apple Developer** (99$ לשנה): לפתוח אותו, להפעיל את ההתחברות עם Apple שמוסתרת מאחורי feature flag, ולבדוק את כל האפליקציה על iPhone (ראו CHANGELOG באפיון, 2026-10-21).
- [ ] **סביבת prod ב-Supabase** בתוכנית Pro.
- [ ] **מסמכים משפטיים:** מדיניות פרטיות, תנאי שימוש ומסמך הגדרות מאגר, אחרי עו"ד.

## לפני ההשקה

- [ ] **שם האפליקציה ומזהה החבילה:** להחליף את הערכים הזמניים (`Travel App`, `com.travelapp.companion`). אי אפשר לשנות את מזהה החבילה אחרי ההעלאה הראשונה ל-Google Play.
- [ ] **node-forge:** לבדוק שיש גרסה מתוקנת לפני שמפעילים חתימה על עדכוני OTA (ראו [dependency-audit.md](../security/dependency-audit.md)).
- [ ] **בדיקת חדירות חיצונית**, כולל זרימת הדרכון (אפיון 6.3).
