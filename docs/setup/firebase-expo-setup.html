1. Firebase וקובץ google-services.json

  • להיכנס ל-console.firebase.google.com וללחוץ Add project. שם הפרויקט, למשל: travel-app-dev. אפשר לוותר על Google Analytics. המסלול הוא החינמי (Spark).
  • בפרויקט שנוצר ללחוץ על סמל ה-Android, להזין את Package name ואת SHA-1 מהמסגרת למעלה ולרשום את האפליקציה.
  • ללחוץ Download google-services.json.
  • לשמור את הקובץ מחוץ לתיקיית הפרויקט, למשל C:\Users\HP\secrets\google-services.json.

2. מפתח FCM V1 ב-expo.dev

  • ב-Firebase: גלגל השיניים, Project settings, הלשונית Service accounts.
  • ללחוץ Generate new private key. יירד קובץ JSON. לשמור אותו גם כן בתיקיית secrets.
  • להיכנס ל-expo.dev, לפתוח את הפרויקט travel-app ולעבור ל-Credentials.
  • לבחור Android ואת com.travelapp.companion, ותחת FCM V1 service account key ללחוץ Upload ולבחור את הקובץ מהשלב הקודם.

את קובץ המפתח לא שולחים לג'ון. מספיק לאשר שהשלב בוצע.

3. EXPO_ACCESS_TOKEN ב-Supabase

  • ב-expo.dev: התמונה שלך, Account settings, Access tokens, ולחיצה על Create token. שם הטוקן, למשל: supabase-push. להעתיק אותו מיד, כי הוא מוצג רק פעם אחת.
  • ב-supabase.com: לפתוח את הפרויקט travel-app-dev ולעבור ל-Edge Functions ומשם ל-Secrets.
  • ללחוץ Add new secret. בשדה Name להזין EXPO_ACCESS_TOKEN, בשדה Value להדביק את הטוקן, ולשמור. זו אותה דרך שבה הוגדר CRON_SECRET.

4. SHA-1 ב-Google Cloud

ב-Firebase הרישום כבר נעשה בשלב 1.

  • להיכנס ל-console.cloud.google.com, לבחור את הפרויקט של ההתחברות עם Google ולעבור ל-APIs & Services ומשם ל-Credentials.
  • לבדוק אם כבר קיים OAuth client מסוג Android עם com.travelapp.companion ועם אותו SHA-1. אם קיים, לא צריך לעשות כלום.
  • אם לא קיים: Create credentials, OAuth client ID, Android, ולהזין את שם החבילה ואת ה-SHA-1.
