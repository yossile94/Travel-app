# חשבונות, כלים ומפתחות

מדריך צעד אחר צעד לכל מה שצריך להכין. לפני כל ספרינט מתווספים כאן השירותים שהספרינט צריך.

**כלל ברזל:** מפתחות לא נשלחים בצ'אט ולא נכנסים לקוד.
- **מפתח של האפליקציה** נשמר בקובץ `.env.local` במחשב שלך, ש-Git מתעלם ממנו, וגם במשתני הסביבה של Expo, כי הבנייה בענן לא רואה את הקובץ המקומי.
- **מפתח של שרת** (למשל של ספק טיסות) נשמר רק ב-secrets של Supabase. הוא לעולם לא נכנס לאפליקציה.
- בכל מקום שצריך מפתח, יש בקובץ `.env.example` שורה עם השם שלו ובלי ערך.

## ספרינט 0

### 1. Expo (בנייה בענן)

**למה:** Expo בונה את האפליקציה בענן ומפיק קישור להתקנה בלי כבל. **לא נדרש כרגע:** בפיתוח בונים ישירות לטלפון דרך USB.

1. להירשם ב-[expo.dev/signup](https://expo.dev/signup). התוכנית החינמית מספיקה. (כבר קיים חשבון, מחובר דרך Google.)
2. בטרמינל של הפרויקט, להריץ:

```bash
npx eas-cli login
```

   הפקודה פותחת את הדפדפן, ושם מתחברים כרגיל, גם עם Google. אין צורך בסיסמה.

3. לבדוק שההתחברות עבדה:

```bash
npx eas-cli whoami
```

   הפקודה צריכה להציג את שם המשתמש שלך. **אתה מקליד את הפרטים, לא אני.**

### 2. Mapbox (הגלובוס והמפות)

**למה:** Mapbox מצייר את הגלובוס.

1. להירשם ב-[account.mapbox.com/auth/signup](https://account.mapbox.com/auth/signup/).
   - **בלי כרטיס אשראי** החשבון הוא חשבון ניסיון: עד 100 משתמשים בחודש באפליקציה. זה מספיק לכל שלב הפיתוח.
   - **לפני הבטא** צריך להוסיף כרטיס. אז נפתחת המכסה החינמית המלאה, כ-25,000 משתמשים בחודש. בתוך המכסה אין חיוב.
2. בדף [Tokens](https://account.mapbox.com/access-tokens/) ללחוץ "Create a token". לתת לו את השם `travel-app`, ולהשאיר את ה-Public scopes שמסומנים כברירת מחדל. המפתח מתחיל ב-`pk.`. יוצרים מפתח ייעודי, ולא משתמשים ב-Default, כדי שאפשר יהיה להחליף אותו בלי לפגוע בדברים אחרים.
3. להעתיק את המפתח לקובץ `.env.local` בשורה `EXPO_PUBLIC_MAPBOX_TOKEN=`.
4. **אחרי שאקים את הפרויקט ב-Expo, ואגיד לך מתי:** באתר expo.dev, בדף הפרויקט, תחת Environment variables, להוסיף משתנה בשם `EXPO_PUBLIC_MAPBOX_TOKEN` עם אותו ערך. ברמת הנראות לבחור Plain text או Sensitive, ולא Secret, כי המפתח הזה נכנס לתוך האפליקציה.

> בעבר Mapbox דרשה גם מפתח הורדה סודי (`sk.`) כדי לבנות את האפליקציה. לפי מדריך ההתקנה העדכני, ב-Android זה כבר לא נדרש. אם זה יידרש כשנבנה ל-iOS, אוסיף כאן הוראות.

### 3. טלפון Android לבדיקות

1. בהגדרות הטלפון: "אודות הטלפון", ואז ללחוץ 7 פעמים על "מספר Build" כדי להפעיל אפשרויות מפתחים.
2. לאפשר התקנה של אפליקציות ממקורות לא ידועים, לדפדפן שבו תפתח את הקישור.
3. בכל ספרינט אשלח קישור להתקנה של הגרסה החדשה.

### 4. הגנה על main ב-GitHub

**למה:** אף שינוי לא נכנס ל-main בלי PR ובלי CI ירוק, גם לא בטעות.

1. במאגר ב-GitHub: Settings, ואז Rules, ואז Rulesets, ואז New ruleset ו-New branch ruleset.
2. Ruleset name: `protect-main`.
3. Enforcement status: לבחור **Active**.
4. Target branches: ללחוץ Add target ולבחור **Include default branch** (הענף `main`).
5. לסמן: Require a pull request before merging, ו-Require status checks to pass. את בדיקת ה-CI בוחרים אחרי שהיא תרוץ פעם ראשונה, ואני אגיד לך את השם שלה.
6. ללחוץ Create.

## להכין עכשיו לקראת ספרינט 1

### 5. חשבון Apple Developer (נדחה, לא לפתוח עכשיו)

**הוחלט לדחות** עד ההכנה ל-iOS ולהשקה, כדי לא לשלם לפני שיש צורך. ההוראות נשארות כאן לאותו שלב.

**למה הוא נדרש:** התחברות עם Apple, גם ב-Android, בנייה ל-iPhone, ופרסום ב-App Store.

1. להירשם ב-[developer.apple.com/programs/enroll](https://developer.apple.com/programs/enroll/) עם ה-Apple ID שלך. העלות היא 99$ לשנה.
2. אפשר להירשם כאדם פרטי או כעסק. רישום כעסק דורש מספר D-U-N-S ולוקח יותר זמן, אבל אז שם העסק יופיע בחנות במקום השם הפרטי שלך.
3. אישור ההרשמה לוקח לפעמים כמה ימים, ולכן כדאי להתחיל עכשיו.

### 7. Docker Desktop

**למה:** מריץ את Supabase על המחשב שלך, כסביבת הפיתוח (dev).

1. להוריד מ-[docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/) את הגרסה ל-Windows.
2. להתקין עם ברירות המחדל. ההתקנה דורשת הרשאות מנהל ומשתמשת ב-WSL 2. אם WSL לא מותקן, ההתקנה תציע להתקין אותו.
3. להפעיל מחדש את המחשב אם מתבקשים.
4. לפתוח את Docker Desktop ולחכות שיופיע "Engine running".
5. **אם מופיעה שגיאה על וירטואליזציה (Virtualization):** צריך להפעיל אותה בהגדרות ה-BIOS של המחשב. האפשרות נקראת Intel VT-x או AMD-V / SVM. אם תצטרך, אדריך אותך צעד אחר צעד.
6. להגיד לי שזה מוכן, ואני אבדוק שהכול עובד.
