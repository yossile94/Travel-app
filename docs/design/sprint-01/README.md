## 0. איך פותחים את ההדמיה

פותחים את `sprint-01.html` בדפדפן עדכני (Chrome או Edge). ההדמיה עובדת גם בלי אינטרנט. אם יש חיבור, נטענים מ-CDN בגרסאות נעולות גם הגופן Rubik וגם מפת מדינות אמיתית (`world-atlas@2.0.2`, ‏110m), ואז הגלובוס מצויר עם מדינות. בלי חיבור מוצג גלובוס סכמטי, והמסכים עצמם לא משתנים.

**ההדמיה מיועדת לפתיחה מקומית בלבד.** הקבצים מה-CDN נטענים בלי SRI (‏`integrity`), ולכן לא מארחים אותה באתר ולא משתמשים בה כבסיס לקוד.

- **בטלפון שבהדמיה הכול לחיץ:** זכוכית מגדלת, הקלדה (במקלדת המחשב או במקלדת שבהדמיה), בחירת תוצאה, כפתור החשבון, ההתחברות, הצ'קבוקסים ו"המשך".
- **Esc** או הכפתור "חזור (Android)" בפאנל מדמים את כפתור החזרה של Android.
- **הפאנל שליד הטלפון** הוא לא חלק מהאפליקציה. אפשר לבחור בו מצב בהיר או כהה, גודל גופן של 100% או 130%, הפחתת תנועה, ולקפוץ לכל מצב של כל מסך: חיפוש ריק, אין תוצאות, Play Services חסר, הסכמה מחדש ועוד.
- **"מה קורא המסך אומר":** בתחתית הפאנל מוצג יומן של ההכרזות שהאפליקציה שולחת לקורא המסך, כמו מספר התוצאות, "נבחרה: תאילנד" ו"התנתקת".
- **מסך "ליטוש הגלובוס"** מחשב בזמן אמת את צינור הצבע של שכבת ה-raster ב-Mapbox (רוויה, ניגודיות, בהירות) על דגימות מייצגות של אוקיינוס, מדבר, יער וקרח. הוא מציג את ערכי ספרינט 0 מול הערכים המוצעים, את טווח היעד של האוקיינוס ואת הניגודיות של האייקונים בשורת הסטטוס ובפס הניווט.

מידות הטלפון: 411×914dp, כמו ה-A73 (1080×2400 בצפיפות 2.625). שורת הסטטוס בגובה 28dp ופס ניווט של שלושה כפתורים בגובה 48dp, שזה המקרה הגרוע. בחלון נמוך הטלפון מוקטן כדי שייכנס כולו.

## 1. מפת מסך הבית: מה יושב איפה

הכלל: **שום רכיב לא מסתיר את הלוגו ואת כפתור הקרדיטים של Mapbox**, בשום מצב שבו רואים את הגלובוס. לכן הם מקבלים "פס" משלהם מתחת לשורת הסטטוס, ופקדי הממשק יושבים בשורה שמתחתיו.

```
 ┌──────────────────────────────────────┐ y=0
 │ 09:41                       ▮▮ 87%   │ שורת סטטוס (insets.top ≈ 28)
 │▒▒▒▒▒▒▒▒▒▒ הצללה עליונה ▒▒▒▒▒▒▒▒▒▒▒▒▒▒│ עד insets.top+16
 │ mapbox (i)                           │ insets.top+12 … +35  (לוגו וקרדיטים)
 │                                      │
 │ [חשבון]                     [חיפוש] │ insets.top+52 … +100 (שורת הפקדים)
 │           ( גלולת מצב / רמז )        │ insets.top+112
 │                                      │
 │                 גלובוס               │
 │                                      │
 │ ┌ כרטיס עלייה ─────────────┬──────┐ │
 │ └──────────────────────────┴──────┘ │ bottom: insets.bottom+16
 │▒▒▒▒▒▒▒▒▒▒ הצללה תחתונה ▒▒▒▒▒▒▒▒▒▒▒▒▒│ insets.bottom+24
 │        ◁        ○        ▢           │ פס ניווט (insets.bottom)
 └──────────────────────────────────────┘
```

| רכיב | מיקום (dp, לוגי) | הערות |
|---|---|---|
| הצללת שורת הסטטוס | `top: 0`, גובה `insets.top + 16` | סעיף 6.4 (AC-9) |
| לוגו Mapbox | `logoPosition = { top: insets.top + 12, left: 12 }` | **[חובה, משפטי]** תמיד גלוי. היום `top+8, left 8`, וזה הוזז ב-4dp כדי שיהיה מתחת להצללה ובקו אחד עם הכפתורים |
| כפתור הקרדיטים | `attributionPosition = { top: insets.top + 12, left: 100 }` | **בלי `hitSlop`**, כי זה רכיב של Mapbox ולא שלנו. הכפתור נגמר ב-`top+35`, ושורת הפקדים מתחילה ב-`top+52`, כך שיש מרווח של 17dp |
| כפתור חיפוש | `top: insets.top + 52`, ‏`start: 12`, ‏48×48 | בצד ההתחלה (ימין בעברית), כי זו הפעולה העיקרית בשורה |
| כפתור חשבון | `top: insets.top + 52`, ‏`end: 12`, ‏48×48 | בצד הסוף (שמאל בעברית), מתחת ללוגו |
| גלולת רמז, גלולת offline, באנר שגיאה והודעה קופצת (toast) | `top: insets.top + 112`, ממורכזות | **שינוי בקוד:** הבאנר `globe.loadError` יושב היום ב-`top+56`, ושם הוא יתנגש בשורת הפקדים. **רק אחת מוצגת בכל רגע:** הודעה קופצת מחליפה את גלולת ה-offline למשך 3 השניות שלה, והגלולה חוזרת אחריה |
| כרטיס העלייה | ללא שינוי (`bottom: insets.bottom + 16`) | |
| הצללת פס הניווט | `bottom: 0`, גובה `insets.bottom + 24` | מתחת לכרטיס |

**למה הלוגו לא בשורה של הכפתורים:** כששדה החיפוש נפתח לרוחב מלא, הוא היה מסתיר את הלוגו. ואם השדה היה נעצר לפני הלוגו, רוחב הטקסט היה כ-160dp בלבד, ובגודל גופן של 130% לא היה נכנס בו אפילו "ארצות הברית". הפס הנפרד עולה 32dp בגובה, אבל בתצוגת הכדור המלא החלק העליון של הכדור מתחיל רק בגובה של כ-225dp, ולכן אין התנגשות עם הגלובוס.

## 2. חיפוש מדינות (F-002)

**המטרה:** להגיע למדינה בלי לסובב את הגלובוס, ביד אחת ובכמה הקשות. "תאי", בחירה, ומיד מעוף וכרטיס.
**קריטריונים:** AC-1 (מיקום ומהירות), AC-2 (תצוגת התוצאות; את כללי ההתאמה עצמם מממשים בקוד), AC-3 (בחירה), AC-4 (התנהגות), AC-5 (offline), AC-6 (נגישות).

### 2.1 מבנה

**סגור:** כפתור עגול "זכוכית" (רכיב `ChromeButton`, סעיף 7.1) עם אייקון זכוכית מגדלת בגודל 24. ‏`accessibilityLabel="חיפוש מדינה"`. האייקון לא מתהפך ב-RTL, כי הוא מייצג עצם.

**פתוח (מלמעלה למטה):**

1. **שדה החיפוש** תופס את כל שורת הפקדים: `start: 12`, ‏`end: 12`, ‏`minHeight: 48`, ‏`radius.pill`. מימין לשמאל:
   - **כפתור חזרה** 48×48, עם חץ "אחורה". **[חובה]** החץ מתהפך ב-RTL, ולכן בעברית הוא מצביע ימינה. ‏`accessibilityLabel="סגירת החיפוש"`.
   - **שדה טקסט:** `body` ‏(16/24), ‏`text.primary`. ה-placeholder הוא "חיפוש מדינה" ב-`text.tertiary`, בשורה אחת. ‏`returnKeyType="search"`, ‏`autoCorrect={false}`, ‏`autoCapitalize="none"`, ‏`autoComplete="off"`, ‏`importantForAutofill="no"`.
   - **כפתור ניקוי** 48×48 עם ×, רק כשיש טקסט. ‏`accessibilityLabel="ניקוי החיפוש"`. ניקוי מחזיר את הפוקוס לשדה ומשאיר את המקלדת פתוחה.
   - **רקע:** במצב בהיר `bg.surface` עם הגבהה 3. במצב כהה `bg.surfaceRaised` עם קו מתאר של 1pt ב-`border.subtle`. כשהשדה בפוקוס (וזה המצב הרגיל כשהמקלדת פתוחה), במקום קו המתאר יש טבעת של 2pt ב-`focus.ring` (4.27–8.89:1).
2. **הצללה על הגלובוס:** מתחת לשדה, מ-`insets.top + 108` ועד תחתית המסך, בצבע `globe.final.searchScrim` (‏`rgba(3,6,15,0.40)`). היא לא מכסה את פס הלוגו. ההצללה מסמנת שעברנו למצב חיפוש, ותופסת הקשות שהיו מגיעות לגלובוס.
3. **רשימת התוצאות:** כרטיס שמתחיל 8dp מתחת לשדה (`top: insets.top + 108`), עם `start/end: 12` ו-`radius.lg`. הרקע כמו של השדה. **גובה מקסימלי:** עד 8dp מעל המקלדת. כשהמקלדת סגורה, עד 16dp מעל פס הניווט. אם התוצאות לא נכנסות, הרשימה נגללת בתוך הכרטיס.
   - **שורת תוצאה** (`minHeight: 56`, ‏`paddingVertical: 8`, ‏`paddingHorizontal: 16`):
     - **שורה ראשונה:** השם בעברית ב-`bodyStrong`, ‏`text.primary`. בטריטוריה, אחרי השם מופיעה מדינת האם בסוגריים, באותו גודל, במשקל 400 וב-`text.secondary`: "איי קוקוס (אוסטרליה)".
     - **שורה שנייה:** השם באנגלית ב-`footnote` ‏(13/18), ‏`text.secondary`, עטוף ב-LTR isolate (כמו `isolateLtr` בכרטיס) ומיושר לימין.
     - **בצד הסוף:** תג קוד `adm0`, למשל `THA`. הוא בגודל 12/16, משקל 500, ספרות טבלאיות וריווח 1.2, ב-`text.secondary` על טוקן ייעודי `bg.tag` (בהיר `#FBF4E8`, ‏6.77:1; כהה `#1A2749`, ‏7.0:1), עם `radius.xs`. התג מבדיל בין שמות דומים, ממשיך את השפה של לוח ההמראות ומופיע גם בספח של הכרטיס. קורא המסך מדלג עליו.
     - **מפרידים:** קו של 1pt ב-`border.subtle`, עם הזחה מצד ההתחלה של 16.
     - **לחוץ:** רקע `bg.pressed` (סעיף 8). עם פוקוס מקלדת או D-pad: טבעת פנימית של 2pt ב-`focus.ring`.
   - **[הצעה] הדגשת החלק שהתאים:** החלק בשם העברי שתואם להקלדה מוצג במשקל 700, ושאר השם ב-500. כך רואים מיד למה התוצאה הופיעה. בהדמיה זה ממומש.
   - **[הצעה] שם נרדף:** כשההתאמה הגיעה רק משם נרדף, כלומר המילה שהוקלדה לא מופיעה באף אחד מהשמות המוצגים, השורה השנייה מסתיימת ב-` · לפי „אנגליה”` ב-`text.tertiary`. כך "אנגליה" ← "בריטניה" לא נראה כמו טעות.
   - **[הצעה] יותר מ-8 התאמות:** שורה לא לחיצה בסוף הרשימה: "יש עוד תוצאות. המשיכו להקליד" (`footnote`, ‏`text.tertiary`, גובה 40).

### 2.3 התנהגות

- **[חובה] כשהחיפוש פתוח, הגלובוס לא מסתובב** (AC-4): `rotationAllowed &&= !searchOpen`. אחרי שהחיפוש נסגר בלי בחירה, ספירת 5 השניות מתחילה מחדש (`setLastInteractionAt`).
- **[חובה] מקש "חיפוש" במקלדת** (‏`onSubmitEditing`) בוחר את התוצאה הראשונה, אם יש כזו. אם אין, לא קורה כלום.
- **הקשה על ההצללה:** אם השדה ריק, החיפוש נסגר. אם יש בו טקסט, ההקשה הראשונה סוגרת את המקלדת והשנייה סוגרת את החיפוש. כך טקסט שהוקלד לא נמחק בטעות.
- **[חובה] "חזור" ב-Android** (AC-4): אם המקלדת פתוחה, Android סוגר קודם אותה, ואת זה אי אפשר ליירט מ-JS. רק הלחיצה הבאה מגיעה ל-`BackHandler` וסוגרת את החיפוש. סדר העדיפויות של "חזור" במסך כולו מוגדר בסעיף 5.5. **לדנה:** הבדיקה של AC-4 היא "חזור, חזור". אם המקלדת כבר סגורה, מספיקה לחיצה אחת. סגירה כזו מנקה את הטקסט ומחזירה את הכרטיס, אם היה פתוח.
- **בחירה באמצע מעוף או כשכרטיס פתוח** (AC-3): מתנהגת כמו `countryTapped` רגיל. הרדוסר הקיים כבר מטפל בזה.
- **כשהחיפוש נפתח שוב, השדה ריק.** לא שומרים את החיפוש הקודם, כי בדרך כלל מחפשים מדינה אחרת.

### 2.5 נגישות (AC-6)

- **[חובה] אזורי לחיצה של 48dp לפחות:** הכפתור, החזרה, הניקוי והשורות (56).
- **[חובה] הכרזה על מספר התוצאות:** טקסט מוסתר ויזואלית עם `accessibilityLiveRegion="polite"`, שמתעדכן 600ms אחרי ההקשה האחרונה (`motion.search.announceDelay`), ורק כשהנוסח השתנה. ב-iOS, בהמשך, אותו טקסט דרך `announceForAccessibility`. הנוסחים כתובים במפורש, בלי `Intl.PluralRules` שלא קיים ב-Hermes:
  - 0: "לא נמצאה מדינה"
  - 1: "נמצאה מדינה אחת"
  - 2–8: "נמצאו {n} מדינות"
  - יותר מ-8: "מוצגות 8 מדינות. המשיכו להקליד כדי לצמצם"
- **[חובה] תווית של שורה:** "תאילנד, Thailand". בטריטוריה: "איי קוקוס, טריטוריה של אוסטרליה, Cocos (Keeling) Islands". ‏`accessibilityRole="button"`. התג `THA` מוסתר מקורא המסך (`importantForAccessibility="no"`).
- **[חובה] טקסט לטיני בשדה** (AC-6): כשמקלידים "usa" או "cote" בממשק בעברית, הטקסט נשאר מיושר לימין, לצד ההתחלה של הממשק, והסמן בצד הנכון לכיוון הפסקה. ב-Android, ‏EditText עם `textDirection: firstStrong` מעביר פסקה לטינית לשמאל אם היישור הוא `start`. לכן צריך יישור מוחלט לימין. ב-RN, ‏`textAlign` מתהפך תחת `I18nManager.isRTL`, אז **בודקים על המכשיר** איזה ערך נותן ימין בפועל, ולא סומכים על ההנחה. **בדיקה לדנה:** "cote" ו-"usa" מוצגים בצד ימין של השדה, וגם "ארה"ב usa".
- **גודל גופן:** השדה והשורות גדלים לגובה (`minHeight`, לא `height`). השמות נשברים לשורה נוספת ולא נחתכים. ה-placeholder בשורה אחת עם `ellipsizeMode="tail"`. ‏`maxFontSizeMultiplier` של 2 (‏`type.maxFontScale.body`).
- **סדר הפוקוס כשהחיפוש פתוח:** חזרה ← שדה ← ניקוי ← התוצאות. כפתור החשבון והגלובוס לא נגישים (`importantForAccessibility="no-hide-descendants"` על שאר המסך).

### 2.6 מימוש (RN)

- **המקלדת:** **[חובה]** הפריסה לא תלויה בשינוי גודל החלון, והגלובוס לא משנה גודל ולא קופץ כשהמקלדת נפתחת:
  - ה-`MapView` נשאר `absoluteFill`, בתוך מכל שגובהו קבוע לגובה המסך (`Dimensions.get('screen').height`) ולא לגובה החלון.
  - הגובה המקסימלי של רשימת התוצאות מחושב מגובה המקלדת, לפי `useAnimatedKeyboard` של Reanimated.
  - `softwareKeyboardLayoutMode` נשאר בברירת המחדל. **בלי `"pan"`.**
  - **נבדק על ה-A73 ביום הראשון של הפיתוח:** פתיחת החיפוש, הקלדה, ו"חזור, חזור". הגלובוס לא זז, והרשימה נגמרת מעל המקלדת.
- **הרשימה:** `FlatList` עם `keyboardShouldPersistTaps="handled"`, כדי שההקשה הראשונה על תוצאה תבחר אותה ולא רק תסגור את המקלדת, ועם `keyboardDismissMode="on-drag"`.
- **ביצועים (AC-1):** החיפוש סינכרוני, על אינדקס שנבנה מראש, בלי debounce לרשימה. ה-debounce הוא רק להכרזה. ‏`[perf] search-results` נרשם אחרי שהתוצאות של אותה שאילתה נכנסו לעץ וצוירו. למשל, `useEffect` שתלוי בשאילתה ומריץ `requestAnimationFrame`, ורושם רק אם השאילתה עדיין זהה. כך מדידה של הקשה ישנה לא נרשמת אחרי הקשה חדשה.
- **הרכיבים:** `SearchButton`/`SearchBar` ב-`features/search/`. הם משתמשים ב-`ChromeButton` (סעיף 7.1), ויושבים מעל ה-`MapView`, באותו עץ כמו הכרטיס.

### 3.2 גיליון החשבון (מחובר)

הקשה על הכפתור פותחת **bottom sheet מודאלי**, לפי הקונבנציה של Android (ב-iOS זה יהיה sheet רגיל).

- **רקע:** `bg.surfaceRaised`, ‏`radius.sheet` בפינות העליונות, ידית אחיזה של 32×4 ב-`border.control`, והצללה מאחור ב-`bg.scrim`. **בפינה העליונה בצד הסוף** כפתור סגירה ×, ‏48×48, ‏"סגירה". **[חובה]** הגיליון נמשך עד תחתית המסך, והתוכן מרופד ב-`insets.bottom`, כך שפס הניווט יושב מעל הרקע של הגיליון.
- **התוכן**, עם ריווח `space.4` מהצדדים:
  - עיגול של 48 עם האות.
  - **השם** ב-`title3`.
  - **המייל** ב-`callout`, ‏`text.secondary`, עטוף ב-LTR isolate ומיושר לימין.
  - "החשבון מחובר דרך Google" ב-`footnote` וב-`text.tertiary`. בלי לוגו של Google, כי לא משתמשים בלוגו מחוץ לכפתור ההתחברות.
- **"התנתקות":** כפתור משני (`action.secondary`) ברוחב מלא ובגובה 48, עם אייקון יציאה שמתהפך ב-RTL. לא באדום, כי Alert שמור לחירום.
- **אין דיאלוג אישור להתנתקות.** הגיליון עצמו הוא כבר צעד אישור, וההתחברות מחדש היא הקשה אחת. **אין** "מחיקת חשבון", "ההסכמות שלי" או פרופיל: אלה בספרינט 2.
- **אחרי התנתקות:**
  - ה-session נמחק (AC-19). גם בלי רשת זה קורה מקומית, וביטול ה-token בשרת הוא best-effort.
  - הגיליון נסגר, והכפתור עובר למצב "לא מחובר" ב-Crossfade של 200.
  - מופיעה הודעה קופצת "התנתקת מהחשבון", למשך 3 שניות.
  - הכרזה לקורא המסך: "התנתקת".

## 5. מסך ההסכמות (AC-16, ‏AC-18)

1. **אין אישור שמור במכשיר:**

   - **מימוש מומלץ:** hook אחד ב-`GlobeScreen` שבוחר את השכבה לפי הסדר הזה, במקום כמה `BackHandler` שמתחרים ביניהם.

### 6.1 בלי נקודות אדומות (AC-7)

- **[חובה]** השכבה `small-countries-dot` יורדת. השכבות `small-countries-hit-wide` ו-`small-countries-hit-tight` נשארות עם `circleOpacity: 0`, כמו היום. ‏`resolveTap` לא משתנה.
- **[חובה] טבעת בחירה למדינה קטנה, רק כשהיא נבחרה.** בלי הנקודה, אם בוחרים את הוותיקן, את מונקו או את המלדיביים, בזום שהמעוף מגיע אליו (זום 6 למדינה קטנה) לא רואים כלום. ההדגשה הרגילה של הפוליגון קטנה מפיקסל. לכן, רק למדינה שנבחרה מתוך רשימת המדינות הקטנות, מציירים טבעת (`CircleLayer` על `small-countries`, עם `filter: ['==', ['get','adm0'], highlightedAdm0]`):
  - **שכבה תחתונה:** `circleRadius: 10`, ‏`circleOpacity: 0`, ‏`circleStrokeWidth: 4`, ‏`circleStrokeColor: #03060F`, ‏`circleStrokeOpacity: 0.6`.
  - **שכבה עליונה:** `circleStrokeWidth: 2`, ‏`circleStrokeColor: #F3F6FC`.
  - **שקיפות:** שתיהן נכנסות עם `circleStrokeOpacityTransition` של 600, כמו ההדגשה.
  - **בלי `maxZoomLevel`:** הטבעת גלויה בכל זום עד 8, המקסימום של המצלמה. הוותיקן ומונקו קטנים מאצבע גם בזום 8.
  - **הצבע לבן ולא כתום,** כדי שלא תחזור "נקודה אדומה", וכדי שהטבעת תתאים לקו המתאר של ההדגשה. **זו החלטה ליוסי** (סעיף 10).

### 6.2 האוקיינוס בתצוגת הכדור המלא (AC-8)

**מה קרה בספרינט 0:** צינור הצבע של שכבת ה-raster ב-Mapbox, כפי שאני מכירה אותו מה-shader של Mapbox GL, ו**צריך לוודא את זה ב-spike**, רץ בסדר הזה על כל ערוץ (0–1):

```
s  = saturation > 0 ? 1 - 1/(1.001 - saturation) : -saturation
c  = c + (avg(r,g,b) - c) * s                        // רוויה
k  = contrast > 0 ? 1/(1 - contrast) : 1 + contrast
c  = (c - 0.5) * k + 0.5                             // ניגודיות
c  = brightnessMin + (brightnessMax - brightnessMin) * c   // בהירות
```

הניגודיות של 0.12 (‏k=1.136) "מוחצת" כל ערוץ שמתחת ל-0.06 לאפס. האוקיינוס של Mapbox Satellite בזום רחוק כהה מאוד, כך שהוא נדחס כמעט לשחור. על דגימה מייצגת `rgb(9,22,48)`, ערכי ספרינט 0 נותנים `#000532`. הרוויה של 0.35 (‏s=‎-0.54) מגבירה את הכרומה פי 1.54, ולכן המדבר נראה "ניאון": `rgb(196,160,112)` הופך ל-`#E6A753`.

**ההצעה, בשתי שכבות:**

1. **תיקון ה-raster** (`RasterLayer`):

   | מאפיין | ספרינט 0 | מוצע | למה |
   |---|---|---|---|
   | `rasterSaturation` | 0.35 | **0.12** | המדבר רגוע יותר. החדות לא נפגעת |
   | `rasterContrast` | 0.12 | **0** | מפסיק למחוץ את הכהים לשחור |
   | `rasterBrightnessMin` | 0 (לא מוגדר) | **0.02** | שום פיקסל לא שחור לגמרי |
   | `rasterBrightnessMax` | 1 (לא מוגדר) | **0.96** | מוריד את הבוהק של הקרח ושל המדבר. עוזר גם ל-AC-9 |

2. **גוון לאוקיינוס** (הטוקן `globe.final.oceanTint` כבר היה קיים, אבל לא מומש). ‏`FillLayer` בשם `ocean-tint`, מעל ה-raster ומתחת לגבולות:
   - **צבע:** `#1561BC` (‏Sky 600).
   - **שקיפות לפי זום:** `['interpolate', ['linear'], ['zoom'], 2, 0.4, 4, 0]`. מלאה עד זום 2, ונעלמת עד זום 4. בזום קרוב, תמונת הלוויין של הים טובה כמו שהיא, כולל המים הרדודים בצבע טורקיז.
   - **המקור: מסכה שנבנית באותו סקריפט ומאותה טופולוגיה.** `scripts/build-countries.mjs` כבר מפשט את מקור 10m מנקודת המבט הישראלית. מאותה טופולוגיה מפושטת, ברמה ה"גסה" (`KEEP_FRACTION 0.05`, כמו היום), מאחדים את כל המדינות ליבשה אחת (`topojson.merge`). התוצאה היא פוליגון אחד של העולם כולו, שהטבעות של היבשה הן החורים בו. הקובץ החדש: `assets/geo/ocean-mask.geojson`. **כך קו החוף של המסכה זהה לגבולות שרואים, נקודה לנקודה.** לא משתמשים ב-`ne_50m_ocean`.
   - **בזום 3–4:** שם כבר מוצגים הגבולות המפורטים (6.5), והמסכה עדיין בנויה מהרמה הגסה. אבל השקיפות שלה שם 0.2 ומטה, ונעלמת עד זום 4, ולכן הפער לא אמור להיראות. בודקים בצילום.

2. צילום מסך. דוגמים ממוצע של 5×5 פיקסלים בחמש נקודות של אוקיינוס פתוח, רחוק מהחוף ומשפת הכדור (באטמוספרה הצבע בהיר יותר).
3. **עובר** אם הממוצע בטווח היעד. אם כהה מדי, מעלים את `oceanTintOpacity` בצעדים של 0.05, עד 0.55. אם בהיר או אפור מדי, מורידים. את ה-raster לא משנים אחרי שהמדבר אושר.
4. צילום שני: זום 3 מעל צפון אפריקה (בדיקת המדבר), ושלישי: ישראל והים התיכון בזום 6 (‏AC-13a). שלושתם נשמרים ב-`docs/design/sprint-01/reference/`, ויוסי מאשר.
5. מודדים שוב 60fps (‏AC-8). שכבת `fill` אחת עם כמה אלפי קודקודים לא אמורה להורגש, אבל מודדים.

**מה לא אפשרי (כמו בספרינט 0):** הברק על הים, הצללה על האוקיינוס והילה חד-צדדית. גם גוון לפי עומק לא אפשרי בלי שכבת בתימטריה (Natural Earth ‏`bathymetry_*`), שהייתה מוסיפה עוד כמה MB. אני לא ממליצה עליה.

### 6.3 המדבריות (AC-8)

### 6.4 שורת הסטטוס ופס הניווט (AC-9)

**הבעיה:** בתצוגת כדור מלא שתי השורות מעל החלל, ואין בעיה. אבל אחרי מעוף או צביטה, תמונת הלוויין מגיעה עד קצה המסך. אייקונים לבנים מעל סהרה שלא כוילה נותנים 2.1:1, ומעל קרח 1.04:1.

**הפתרון: שתי שכבות הצללה קבועות.** הן מצוירות ב-`react-native-svg` (‏`Svg` עם `LinearGradient` ו-`Rect`, כי `expo-linear-gradient` לא מותקן), מעל ה-`MapView` ועם `pointerEvents="none"`:

| תחתונה | `insets.bottom + 24` | התחלה: 0 · ‏24dp: ‏0.5 · תחתית: 0.6 |

**חישוב לפי WCAG על הרקעים הגרועים ביותר, באמצע גובה האייקונים (alpha של כ-0.55):**

| רקע מתחת | בלי הצללה | עם הצללה |

| סהרה (מכויל, `#C29C69`) | 2.5:1 ✗ | **8.5:1** ✓ |
| קרח באנטארקטיקה (מכויל, `#DEE5EB`) | 1.2:1 ✗ | **5.4:1** ✓ |

- **הסף:** מעל קרח מכויל מספיק alpha של כ-0.35, אבל מעל ענן או קרח לבנים לגמרי 3:1 דורש כ-0.45. **לכן 0.5 היא הרצפה, ולא ערך עם מרווח גדול.** לא מורידים מתחת ל-0.5.
- **[חובה] סגנון האייקונים בפס הניווט לפי המשטח העליון:**
  - **מעל הגלובוס:** אייקונים בהירים.
  - **כשגיליון או מסך ההסכמות במצב בהיר הם המשטח העליון:** אייקונים כהים.
  - **במצב כהה:** בהירים תמיד.
  - אותו כלל חל על שורת הסטטוס, דרך `expo-status-bar` (מותקן).
- **המנגנון:**
  - **הקיים:** ב-SDK 58 edge-to-edge הוא חובה. ההגדרה הקבועה נקבעת ב-`app.json` (‏`androidNavigationBar`): אייקונים בהירים, ובלי הניגודיות האוטומטית של Android (`enforceContrast: false`). בלי זה, בניווט של שלושה כפתורים מתקבלת הצללה כפולה, ובניווט במחוות אין הצללה בכלל.
  - **החסר:** להחלפה בזמן ריצה צריך API. `expo-navigation-bar` **לא מותקן**, ולכן ב-PR של F-003a: או שמוסיפים אותו (`npx expo install`, באישור רז), או שמוצאים דרך אחרת שקיימת ב-SDK 58.
  - **לאמת:** את שמות המפתחות ב-`app.json` בודקים מול התיעוד של SDK 58.
- **[חובה] נבדק על ה-A73 במצב ניווט של שלושה כפתורים:**
  - הגלובוס בזום קרוב מעל סהרה.
  - גיליון החשבון במצב בהיר.
  - מסך ההסכמות במצב בהיר ובמצב כהה.
- **עלות:** שתי Views שקופות, בלי השפעה על המשטח של Mapbox.

### 6.5 גבולות חדים יותר (AC-13a)

- **שתי רמות פירוט מאותו מקור:** `scripts/build-countries.mjs` בונה כבר היום את `countries.geojson` ממקור 10m מנקודת המבט הישראלית, עם `KEEP_FRACTION 0.05`. **זה לא 50m.** לכן הרמות נקראות לפי רמת הפישוט:
  - **"גסה" (coarse):** הקובץ של היום, `KEEP_FRACTION 0.05`, ללא שינוי. מוצגת עד זום 3.
  - **"מפורטת" (detailed):** אותו מקור 10m ואותו סקריפט, עם `KEEP_FRACTION` גבוה יותר. מוצגת מזום 3. **ערך התחלתי:** 0.25. דורי מכוון לפי תקציב הגודל ולפי הצילום, וזה הערך שמשנים אם הקובץ גדול מדי. קובץ חדש: `assets/geo/countries-detailed.geojson`.
- **[חובה] המקור המפורט נטען בעצלות, אף פעם לא בפריים הראשון.** ה-`ShapeSource` שלו נטען אחרי `[perf] globe-ready`, או בפעם הראשונה שהזום עובר 2.5, מה שקורה קודם.
  - **עד שהוא מוכן,** השכבות הגסות מוצגות בכל זום (בלי `maxZoomLevel`).
  - **אחרי שהוא מוכן,** השכבות הגסות מוגבלות ל-`maxZoomLevel: 3`, והמפורטות מקבלות `minZoomLevel: 3`.
- **[חובה] `maxZoomLevel` מפורש לשני ה-`ShapeSource`** (רמת האריחים של geojson-vt; המצלמה עוצרת ב-8):
  - **הגס:** `maxZoomLevel={3}`. מעל זה האריחים מוגדלים, וזה מספיק לפירוט שלו.
  - **המפורט:** `maxZoomLevel={8}`.
  - **היום:** המקור היחיד מוגדר עם 6.
- **[חובה] לכל מקור מזהי שכבות משלו**, כולל שכבות כפולות להקשה ולהדגשה:
  - **גס:** `countries-coarse-hit`, ‏`countries-coarse-border`, ‏`highlight-coarse-fill`, ‏`highlight-coarse-glow`, ‏`highlight-coarse-underlay`, ‏`highlight-coarse-outline`.
  - **מפורט:** `countries-detailed-hit`, ‏`countries-detailed-border`, ‏`highlight-detailed-fill`, ‏`highlight-detailed-glow`, ‏`highlight-detailed-underlay`, ‏`highlight-detailed-outline`.
  - **הקשה:** שואלת את **שתי** שכבות ההקשה (`queryRenderedFeaturesAtPoint` עם שני המזהים). בכל זום רק אחת מהן מצוירת, ולכן לכל היותר אחת עונה. כך מה שרואים הוא מה שלוחצים ("ליד רומא ← איטליה").
  - **הדגשה:** אותו `filter` ואותם סגנונות על שני הסטים.
- **[חובה] מדידות** (ב-PR של F-001.1, בבניית preview על ה-A73, לפני ואחרי):
  - **גודל ה-APK:** התוספת של המקור המפורט ושל מסכת האוקיינוס יחד, עד 5MB (AC-13a).
  - **פתיחה קרה:** AC-1 ו-AC-14a, עם נקודת הסיום החדשה (תמונת הלוויין מצוירת).
  - **זיכרון native:** PSS מ-`adb shell dumpsys meminfo <package>`, לפני ואחרי. נמדד בתצוגת כדור מלא, ואחרי זום לישראל ב-6 שבו המקור המפורט נטען.
- **עובי הקו לפי זום:**

  | זום | 0 | 3 | 5 | 8 |
  |---|---|---|---|---|
  | עובי (dp) | 0.5 | 0.75 | 1.0 | 1.6 |
  | פיקסלים פיזיים ב-A73 | 1.3 | 2.0 | 2.6 | 4.2 |

  `lineWidth: ['interpolate', ['linear'], ['zoom'], 0, 0.5, 3, 0.75, 5, 1, 8, 1.6]`, ‏`lineBlur: 0`, ‏`lineJoin: 'round'`, ‏`lineCap: 'round'`. הצבע לא משתנה (`globe.final.border`).
- **המעבר בזום 3 (מגס למפורט):** החלפה חדה. הקווים כמעט חופפים, ובעובי של 2 פיקסלים הקפיצה כמעט לא נראית. **אם היא נראית בצילום על ה-A73:** crossfade בין זום 2.8 ל-3.2 (שתי השכבות עם `lineOpacity` לפי זום). זה עולה ציור כפול ברצועה צרה בלבד.

### 6.6 שם ארוך בכרטיס (AC-11)

- **[חובה]** `numberOfLines={2}`, ‏`ellipsizeMode="tail"`, ‏`accessibilityLabel={nameHe}` המלא. ‏`maxFontSizeMultiplier: 1.6`, כמו כל `title1`.
- **[חובה] הקטנה לשם ארוך:** שם של עד 16 תווים מוצג ב-`title1` ‏(28/34). שם ארוך יותר מוצג ב-`title2` כמו שהוא בטוקנים (22/28, משקל 600), בלי משקל מיוחד. כך "איי ג'ורג'יה הדרומית ואיי סנדוויץ' הדרומיים" נכנס בשתי שורות בגודל 100%, ובגודל 130% נחתך עם שלוש נקודות אחרי שתי שורות. הסף הוא `layout.card.nameStepDownChars`.
- **השם באנגלית:** שורה אחת עם שלוש נקודות (הוא כבר באותיות גדולות ומרווח), והשם המלא ב-`accessibilityLabel`.
- **השדות (שעה ומטבע):** `flexWrap: 'wrap'`. בגודל 130%, אם השדות לא נכנסים זה לצד זה, המטבע יורד לשורה. **ההפרש משעון ישראל לא נחתך לעולם**, הוא נשבר לשורה נוספת.
- **כפתור הסגירה:** גדל מ-44 ל-48 (‏`size.touchTarget.min` עולה ל-48, סעיף 8). לכן גם הריווח בצד הסוף (`clearOfClose`) עולה ל-48, והוא נשאר על שתי השורות של השם. זה מבזבז מעט מקום בשורה השנייה, אבל מבטיח שהטקסט אף פעם לא נכנס מתחת ל-×.

### 6.7 נוסח ההפרש משעון ישראל (AC-12, החלטה 3)

הנוסח מחליף את `timeDifference.*` שב-`he.json`. ‏"יותר" פירושו שהשעון שם מראה שעה מאוחרת יותר. גם כאן אין `Intl.PluralRules`, ולכן כל צורה כתובה במפורש:

| הפרש | נוסח | דוגמה |
|---|---|---|
| 0 | **כמו בישראל** | יוון, קפריסין |
| ‎+1:00 / ‏‎-1:00 | שעה יותר מבישראל / שעה פחות מבישראל | גאורגיה בקיץ / איטליה |
| ‎±2:00 | שעתיים יותר / פחות מבישראל | |
| ‎±n:00 | **{n} שעות** יותר / פחות מבישראל | "6 שעות פחות מבישראל" (ברזיל, בקיץ הישראלי) · "7 שעות פחות מבישראל" (ניו יורק) |
| ‎±0:30 | חצי שעה יותר / פחות מבישראל | |
| ‎±1:30 | שעה וחצי יותר / פחות מבישראל | אפגניסטן |
| ‎±2:30 | שעתיים וחצי יותר / פחות מבישראל | הודו |
| ‎±n:30 | {n} שעות וחצי יותר / פחות מבישראל | |
| ‎±0:45 | 45 דקות יותר / פחות מבישראל | |
| ‎±h:mm (אחר) | שעה ו-{mm} דקות / שעתיים ו-{mm} דקות / {n} שעות ו-{mm} דקות, יותר / פחות מבישראל | נפאל בקיץ הישראלי: "שעתיים ו-45 דקות יותר מבישראל" (ולא "2 שעות") |

מפתחות מוצעים ל-i18n:
- `timeDifference.same`: "כמו בישראל"
- `ahead`: "{{amount}} יותר מבישראל"
- `behind`: "{{amount}} פחות מבישראל"
- `oneHour`: "שעה", ‏`twoHours`: "שעתיים", ‏`hours`: "{{n}} שעות"
- `halfHour`: "חצי שעה", ‏`oneAndHalf`: "שעה וחצי", ‏`twoAndHalf`: "שעתיים וחצי", ‏`hoursAndHalf`: "{{n}} שעות וחצי"
- `minutes`: "{{m}} דקות"
- `oneHourMinutes`: "שעה ו-{{m}} דקות", ‏`twoHoursMinutes`: "שעתיים ו-{{m}} דקות", ‏`hoursMinutes`: "{{n}} שעות ו-{{m}} דקות"

המפתח הקיים `hoursMinutes` ("2:30 שעות") מקבל נוסח חדש.

**AC-12 "אפגני":** תיקון נתונים בלבד. בכרטיס: "אפגני", ובשורה מתחת "؋ · AFN".

## 7. רכיבים חדשים (נוספים למערכת העיצוב)

### 7.1 `ChromeButton`: כפתור עגול מעל הגלובוס
- **מידות:** 48×48, ‏`radius.pill`. האייקון בגודל 24 ב-`chrome.fg`.
- **רקע:** `chrome.bg`. בבהיר `rgba(255,255,255,0.92)` עם הגבהה 2. בכהה `rgba(18,28,54,0.88)` עם קו מתאר של 1dp ב-`chrome.border`.
- **ניגודיות האייקון,** גם מעל קרח: 14.1:1 בבהיר ו-11.5:1 בכהה.
- **לחוץ:** scale ל-0.96 ב-100 (`micro`), ו-ripple ב-Android.
- **בלי טשטוש (blur).** ‏`expo-blur` ב-Android עולה פריימים מעל המשטח של Mapbox, וב-92% אטימות זה כמעט לא נראה.

### 7.2 שדה חיפוש ורשימת תוצאות
ראו סעיף 2.1.

### 7.3 `CheckboxRow`
- **שורה:** `minHeight` של 56 (48 לשורה בלי טקסט משני), ‏`paddingVertical: 12`. כל השורה לחיצה (`accessibilityRole="checkbox"` ו-`accessibilityState.checked`).
- **הריבוע:** 24×24 בצד ההתחלה, ‏`radius.xs`.
  - **לא מסומן:** קו של 2dp ב-`border.control` (3.6:1 / ‏5.2:1).
  - **מסומן:** מילוי `action.primary.bg` ו-✓ ב-`action.primary.fg`.
- **רווח** של 12 בין הריבוע לטקסט.
- **הטקסט:** תווית ב-`body` (בשורת החובה `bodyStrong`), ותיאור ב-`footnote` וב-`text.secondary`.

### 7.4 `InlineNotice`
`status.info.subtleBg/fg`, אייקון 20, ‏`radius.md`, ריווח של 12. ‏`accessibilityLiveRegion="polite"`. משמש לשגיאות שאינן חירום. האדום נשאר לחירום (סעיף 1.3 במערכת העיצוב).

### 7.5 `Toast` (הודעה קופצת)
- **מיקום:** `top: insets.top + 112`, ממורכזת, עם `maxWidth` של רוחב המסך פחות 48.
- **נראות:** רקע `toast.bg` (‏`#121C36`) וטקסט `toast.fg` (‏`#F3F6FC`), ב-15.6:1. ‏`radius.pill`, ‏`callout`.
- **זמן:** 3 שניות (`motion.toast.visible`). אין בה כפתור, ולכן היא לא חוסמת.
- **בשני המצבים כהה,** כי היא תמיד מעל הגלובוס.
- **קורא מסך:** מוכרזת דרך live region.

### 7.6 bottom sheet מודאלי
- **נראות:** `bg.surfaceRaised`, ‏`radius.sheet`, ידית 32×4, × של 48. הגיליון נמשך עד תחתית המסך, והתוכן מרופד ב-`insets.bottom`. סגנון האייקונים בפס הניווט לפי 6.4.
- **הצללה:** `bg.scrim`. היא מעמעמת גם את הלוגו של Mapbox, אבל לא מסתירה אותו. זה מקובל בחלון מודאלי, ורז מאשר.
- **סגירה:** "חזור", גרירה למטה או הקשה על ההצללה.
- **פוקוס:** כשהגיליון נפתח, הפוקוס עובר לכותרת.

## 9. הערות למימוש (לרז ולדורי)

1. **מיקום הלוגו:** `logoPosition` ו-`attributionPosition` עוברים ל-`top: insets.top + 12` ו-`left: 12` / ‏`left: 100` (היום 8 ו-92). הבאנר `globe.loadError` עובר ל-`top: insets.top + 112`.
2. **המקלדת והגלובוס:** מכל בגובה המסך, ובלי `"pan"` (2.6). נבדק ביום הראשון.
3. **"חזור":** סדר אחד ושכבה אחת שמטפלת (5.5). עם מקלדת פתוחה, Android סוגר קודם את המקלדת (2.3). זו מגבלה של Android, ולא באג.
4. **סדר השכבות החדש** (מלמטה למעלה):
   - `background`
   - `satellite` (raster, עם 4 המאפיינים)
   - **`ocean-tint`** (מקור `ocean-mask`)
   - **מקור גס** (`countries-coarse`, ‏`maxZoomLevel={3}`):
     - `countries-coarse-hit`
     - `countries-coarse-border`
     - `highlight-coarse-fill`, ‏`-glow`, ‏`-underlay`, ‏`-outline`
   - **מקור מפורט** (`countries-detailed`, ‏`maxZoomLevel={8}`, נטען בעצלות, השכבות מ-`minZoomLevel: 3`):
     - `countries-detailed-hit`
     - `countries-detailed-border`
     - `highlight-detailed-fill`, ‏`-glow`, ‏`-underlay`, ‏`-outline`
   - **`small-selection-ring-underlay`** ו-**`small-selection-ring`**
   - `small-countries-hit-wide`, ‏`small-countries-hit-tight`

   **יורדות:** `small-countries-dot`, והמזהים הישנים `countries-hit`, ‏`countries-border` ו-`highlight-*` (בלי רמה). ‏`LAYER` ב-`GlobeLayers.tsx` מתעדכן, ו-`onPress` שואל את שתי שכבות ה-hit של המדינות.
5. **מיתוג Google:** לאמת את סעיף 4.3 מול הדף הרשמי ב-PR של F-003a, במיוחד את הצד של הלוגו ב-RTL, את הגופן ואת הרווח של 10dp.
6. **הסכמות בלי רשת:** בלי אישור שמור, המסך מוצג גם בלי רשת. בדיקת גרסה חדשה רק עם רשת (5.3, 5.5).
7. **"פג תוקף" רק ב-`invalid_grant`** (4.2). מרגע שההחלפה מול Supabase התחילה, אין ביטול (5.5).
8. **פס הניווט:** החלפת סגנון לפי המשטח העליון דורשת API בזמן ריצה, ו-`expo-navigation-bar` לא מותקן (6.4).
9. **מחרוזות:** כל הנוסחים כאן הם הנוסח הסופי לעברית, ונכנסים ל-`he.json`. ב-`en.json` מתרגמים, ושם אין בעיית מגדר. נוסח עם לוכסן (מאשר/ת) מופיע רק איפה שהאפיון דורש אותו.

- **לא פתחתי את ההדמיה בדפדפן.** בסבב הזה לא היה לי דפדפן, ולכן הכול נבדק בקריאת קוד. **צ'קליסט לפתיחה הראשונה:**

  - "תאי" מציג את תאילנד ראשונה.
  - "ארה" מציג את ארצות הברית ראשונה. גם "usa", "אמריקה", "אנגליה", "cote", "טגיק", "מלד" ו"ותיק" עובדים.
  - "איי" מציג טריטוריות עם מדינת האם.

  - הצ'קבוקס פותח את "המשך".
  - בגודל 130% שם הבדיקה הארוך נחתך בשתי שורות.
  - במסך הליטוש, המספרים תואמים לטבלאות בסעיף 6.

- **הניגודיות** חושבה בנוסחת WCAG 2.x. את ערבוב ההצללה חישבתי במרחב sRGB, כמו ש-Android מרכיב שכבות.
