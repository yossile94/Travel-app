## 1. כרטיס המדינה: סדר השדות ותקציב הגובה

**המטרה:** לפני שיוצאים, הכרטיס עונה לפי הסדר: אפשר להיכנס? כמה בטוח? מה השעה? כמה זה עולה? איזה מזג אוויר?

### 1.1 הסדר **[חובה]**

```
 ┌ יעד ──────────────────────────┬────────┐
 │ תאילנד                      × ┆  THA   │
 │ THAILAND                      ┆        │
```

1. **תג כניסה** (סעיף 5): רק ב-`restricted` או `banned`. מתחת לשם באנגלית, `marginTop: 8`.
2. **אזהרת המל"ל** (סעיף 6): שורה ברוחב העמודה, `marginTop: 12`.
3. **שעה ומטבע:** בלי שינוי (`flexWrap`, ‏`gap: 20`).
4. **שער חליפין** (סעיף 2): בלוק ברוחב העמודה, מתחת לשדות, `marginTop: 12`. הוא לא נכנס לשורת השדות, כי השורה שלו ארוכה (בערך 230dp ב-100%) ותמיד הייתה דוחפת את השדות האחרים.
5. **טמפרטורה:** כמו בספרינט 3, **בלי** "מקורות" מתחתיה.
6. **"מקורות":** אחרון בעמודה, `marginTop: 8`. **[חובה]** מוצג כשמוצג לפחות אחד מאלה: טמפרטורה, שער (כולל "אין שער זמין"), אזהרה (כולל "בהשלמה"). הגיליון מכסה עכשיו את כולם (סעיף 11). הכלל של ספרינט 3 ("מוסתר כשאין טמפרטורה") מתעדכן.

**למה הסדר הזה:** כניסה ובטיחות הן החלטת "לנסוע או לא", ולכן הן ראשונות. השעה נשארת במקום שהמשתמשים מכירים. השער צמוד למטבע שהוא מסביר. הטמפרטורה נשארת אחרונה, כמו שהוחלט בספרינט 3.

**ישראל (`ISR`):** אין תג, אין אזהרה ואין שער (ILS). הכרטיס נראה כמו היום. **[חובה]** אזור שאינו ISR אבל משתמש ב-ILS: אין שורת שער, ושאר השדות רגילים.

### 1.3 מצב גלילה של הכרטיס **[חובה]**

**הכלל:** כש-`passHeight + COUPON_CHROME + size.tripRow.min (72) > maxCardHeight`, הכרטיס עובר ל"מצב גלילה":
- **כל התוכן** (הכרטיס והקופון) נמצא ב-`ScrollView` אחד עם `maxHeight = maxCardHeight`. הרשימה בקופון מאבדת את הגלילה שלה (בלי גלילה מקוננת), ו-`maxListHeight` הוא `Infinity`.
- **ה-× נשאר קבוע** בפינה (הוא כבר `position: absolute` מחוץ לתוכן). במצב גלילה מקבל רקע עגול 40 ב-`bg.surfaceRaised` (כהה: עם קו `border.subtle`), כדי שהשם לא ייראה דרכו כשגוללים.
- **הרקע של כרטיס העלייה** (ה-SVG עם החורים והקו המקווקו) נמצא בתוך תוכן הגלילה ונמדד לפי התוכן, לא לפי ה-ScrollView.
- **[חובה] גלילה לנסיעה הפתוחה:** כשהכרטיס נפתח עם נסיעה פתוחה (הקשה על הפין, "הנסיעות שלי", AC-8), גוללים את ה-ScrollView החיצוני כך שהשורה הפתוחה מתחילה 16dp מתחת לראש הגלילה. היום זה קורה ברשימה הפנימית, ובמצב גלילה זה עובר לחיצונית.
- **הכרטיס מופיע בגלילה 0** (השם למעלה) בכל מקרה אחר.
- **[הצעה]** צל עדין (גובה 8, ‏`bg.surfaceRaised` לשקוף) בתחתית ה-ScrollView כשיש עוד תוכן מתחת, כדי שיהיה ברור שאפשר לגלול.

**למה לא לקצץ שדות במקום זה:** כל שדה כאן הוא קריטריון קבלה, ובהגדלת טקסט אסור לחתוך. מצב גלילה הוא שינוי אחד שפותר גם את 200%.

**למה לא תמיד במצב גלילה:** ב-100%, במקרה הרגיל, רשימה שנגללת לבד מתחת לכרטיס קבוע היא חוויה טובה יותר: השעה והשער נשארים בעין כשעוברים בין נסיעות.

### 1.4 נגישות: סדר הפוקוס בכרטיס

שם המדינה ← × ← **תג הכניסה** ← **שורת האזהרה** ← השעה ← המטבע ← **שורת השער** ← **"עודכן ב-"** (כולל "ייתכן שלא מעודכן") ← **הייחוס** (קישור) ← הטמפרטורה ← **"מקורות"** ← הקוד ← "הנסיעות שלך" ← השורות ← "נסיעה חדשה".

## 3. כללי התצוגה של השער **[חובה]**

כולם בפונקציה טהורה אחת (`formatRateLine(rateToIls, usdIls, code)`) עם בדיקות יחידה. גם הכרטיס, גם המחשבון וגם ההדמיה משתמשים באותו אלגוריתם.

### 3.1 מספר היחידות

- היחידות האפשריות: 1, 10, 100, 1,000, 10,000. בוחרים את **הקטנה ביותר** שבה `rateToIls × units ≥ 0.1`.
- **[חובה] ההשוואה על הערך המלא, לפני עיגול.** בדיקה: ‏`rateToIls = 0.00999` ← ‏`× 10 = 0.0999 < 0.1` ← ‏100 יחידות ("100 X = 1.0 ₪"), ולא "10 X = 0.10 ₪".
- אם גם ב-10,000 הערך קטן מ-0.1, נשארים עם 10,000.

### 3.2 עיגול ל-2 ספרות משמעותיות

- `x.toPrecision(2)`, **עם אפסים בסוף** ("4.0", ‏"0.10"), כדי שהדיוק ייראה אחיד בין מטבעות. לא מסירים אותם.
- **ערך ≥ 100** (‏`toPrecision` נותן "1.2e+2"): ‏`Math.round(x / 10^(d-2)) × 10^(d-2)` כמספר שלם ("120"). בפועל זה לא אמור לקרות ב-₪ (המטבע היקר ביותר בערך 12 ₪), אבל הפונקציה חייבת לא להחזיר "e".
- **הדולר מחושב מהערך המלא:** ‏`usd = rateToIls × units / usdIls`, ואז עיגול. לא מעגלים פעמיים.
- **אלפים:** פסיק במספר היחידות ("1,000", ‏"10,000"). בשתי השפות נקודה עשרונית ופסיק לאלפים, כמו המקובל בישראל. בלי `toLocaleString` (Hermes).

### 3.3 הנוסח והכיוון

- **הנוסח:** ‏`{{units}} {{code}} = {{ils}} ₪ · {{usd}} $`. ב-USD: ‏`1 USD = {{ils}} ₪`.
- **[חובה] קוד ISO, לא סמל** ("THB" ולא "฿"), כמו בדוגמה של AC-1. הסמל כבר מופיע בשדה המטבע שמעל, וסמלים של מטבעות רבים (כמו ‏.د.ب) מבלבלים את הכיוון.
- **[חובה] כל השורה עטופה ב-isolate של LTR** (‏LRI … PDI, הפונקציה `isolateLtr` הקיימת). בעברית היא מוצגת בדיוק כמו באנגלית: "1,000 VND = 0.12 ₪ · 0.038 $", משמאל לימין, ומיושרת לצד ההתחלה (ימין) של העמודה. בלי העטיפה, ה-"₪" וה-"$" (תווים ניטרליים) קופצים לצד הלא נכון.
- **הסמל אחרי המספר עם רווח** ("0.12 ₪"), כמו בדוגמה. ‏" · " הוא U+00B7 עם רווחים.

### 3.4 בדיקות יחידה (AC-1)

הערכים הם **להדגמה**. הבדיקות בונות את `rateToIls` ו-`usdIls` בעצמן, ובודקות את הכללים ולא שער אמיתי. עם `usdIls = 3.2`:

| מטבע | `rateToIls` | שורה צפויה |
|---|---|---|
| EUR | 3.72 | `1 EUR = 3.7 ₪ · 1.2 $` |
| THB | 0.11 | `1 THB = 0.11 ₪ · 0.034 $` |
| THB (שער נמוך) | 0.0952 | `10 THB = 0.95 ₪ · 0.30 $` (‏0.0952 < 0.1, ולכן 10) |
| JPY | 0.0213 | `10 JPY = 0.21 ₪ · 0.067 $` |
| VND | 0.000122 | `1,000 VND = 0.12 ₪ · 0.038 $` |
| IDR | 0.000198 | `1,000 IDR = 0.20 ₪ · 0.062 $` |
| USD | 3.2 | `1 USD = 3.2 ₪` |
| ILS | — | `null` (אין שורה) |
| גבול | 0.00999 | `100 X = 1.0 ₪ · 0.31 $` |
| יקר | 12.3 | `1 KWD = 12 ₪ · 3.8 $` |

כל בדיקה בודקת גם את התווים: ‏U+2066 בהתחלה, ‏U+2069 בסוף, ו-U+00B7.

**שימו לב לדוגמה ב-AC-1:** "0.04 $" שם היא ספרה משמעותית **אחת**. לפי הכלל של 2 ספרות זה "0.038 $". אני הולכת לפי הכלל (שאלה 3 בסעיף 19).

## 4. המחשבון (F-012: AC-2)

### 4.1 הגיליון

**אותו `BottomSheet` עם `KeyboardAvoidingView`**, כמו גיליון הנוסע בספרינט 3. נפתח מעל הכרטיס, והכרטיס נשאר מאחור.

```
 ┌──────────────────────────────────────────┐
 │                 ───                       │  ידית
 │ מחשבון מטבע                           ×  │  title2
 │ 1,000 VND = 0.12 ₪ · 0.038 $             │  callout, text.secondary
 │                                          │
 │ דונג וייטנאמי · VND                       │  caption
 │ ┌──────────────────────────────── VND ┐  │
 │ │ 1000                                 │  │  TextField, 56
 │ └──────────────────────────────────────┘  │
 │ שקל חדש · ILS                             │
 │ ┌──────────────────────────────── ₪ ──┐  │
 │ │ 0.12                                 │  │
 │ └──────────────────────────────────────┘  │
 │ דולר אמריקאי · USD                        │
 │ ┌──────────────────────────────── $ ──┐  │
 │ │ 0.04                                 │  │
 │ └──────────────────────────────────────┘  │
 │ שער להמחשה בלבד; השער בבנק או בצ'יינג'   │  footnote, text.secondary
 │ יהיה שונה                                │
 │ עודכן ב-26.10.2026 · Rates By Exchange   │  footnote
 │ Rate API                                 │
 └──────────────────────────────────────────┘
```

- **כותרת:** "מחשבון מטבע" (`title2`), ומתחתיה שורת השער (`callout`, ‏`text.secondary`, אותה מחרוזת של 3.3), כדי שיהיה ברור לפי מה מחשבים.
- **שלושה שדות, בעמודה, לפי הסדר:** המטבע המקומי ← ₪ ← $. **[חובה]** התווית של כל שדה היא שם המטבע וקוד ("באט תאילנדי · THB", ‏"שקל חדש · ILS", ‏"דולר אמריקאי · USD"), והקוד/הסמל מופיע גם בתוך השדה, בצד הסוף, ב-`text.secondary`.
- **השדה:** ה-`TextField` של ספרינט 2, ‏`minHeight: 56`, ‏`numeric.md` עם ספרות טבלאיות, ‏`keyboardType="decimal-pad"`, ‏`autoCorrect={false}`, ‏`selectTextOnFocus`. **[חובה] הטקסט בשדה LTR** (`writingDirection: 'ltr'`) ומיושר לצד ההתחלה של הממשק (בעברית `textAlign: 'right'`, לפי ההערה על EditText ב-`SearchBar.tsx`).
- **מצב פתיחה:** בשדה המקומי מספר היחידות של השורה ("1000", בלי פסיק), והשניים האחרים מחושבים. **[חובה] הפוקוס והמקלדת בשדה המקומי**, והטקסט מסומן, כך שההקלדה הראשונה מחליפה אותו. זה המקרה הנפוץ: "כמה זה 450 באט?".
- **אחרי השדות:** שורת האחריות הקבועה (AC-5), "עודכן ב-" עם התג אם צריך, והייחוס (קישור), כמו בכרטיס.
- **סגירה:** ×, "חזור" (קודם המקלדת נסגרת, על ידי Android), הקשה על הרקע. **שום דבר לא נשמר**: בפתיחה הבאה הערכים מתחילים מחדש. הפוקוס חוזר לשורת השער בכרטיס.

### 4.2 החישוב **[חובה]**

- **עריכה של שדה אחד מעדכנת את שני האחרים בכל הקשה**, בלי כפתור "חשב".
  - מקומי: ‏`ils = x × rateToIls`, ‏`usd = ils / usdIls`.
  - ₪: ‏`local = x / rateToIls`, ‏`usd = x / usdIls`.
  - $: ‏`ils = x × usdIls`, ‏`local = ils / rateToIls`.
- **תמיד מחשבים מהשדה שנערך לאחרונה**, אף פעם לא מערך מחושב שעוגל, כדי שלא יצטברו שגיאות עיגול.
- **התוצאה:** 2 ספרות אחרי הנקודה, בלי פסיקי אלפים (שדה שאפשר לערוך). **[הצעה]** פסיקי אלפים בשדות המחושבים.
- **שדה ריק** ← השניים האחרים ריקים. "0" ← "0.00".
- **תוצאה מעל 12 ספרות שלמות** (למשל 999,999,999,999 ₪ ל-VND): השדה המחושב מציג "—" ולא מספר חתוך. מקרה תיאורטי, אבל אסור שיהיה `Infinity` או `e+`.

### 4.3 כללי הקלט **[חובה]** (AC-2)

| מקרה | מה קורה |
|---|---|
| ספרות | מתקבלות |
| `.` או `,` | שניהם מתקבלים כנקודה עשרונית. **הפסיק מוצג כנקודה** מיד (‏"12,5" ← "12.5"), כדי שבשדה תהיה צורה אחת |
| נקודה עשרונית שנייה | ההקשה נדחית (השדה לא משתנה) |
| ספרה 13 לפני הנקודה, או ספרה שלישית אחריה | ההקשה נדחית |
| נקודה בהתחלה ("‎.5") | מתקבלת, ומוצגת "0.5" |
| אפסים מובילים ("007") | מתקבלים כמו שהם; לחישוב זה 7. **[הצעה]** לנקות ב-blur |
| **הדבקה** | כל המחרוזת נבדקת אחרי trim: ספרות, לכל היותר נקודה או פסיק אחד, עד 12/2. **[חובה] אם היא לא חוקית, נדחית כולה**, והשדה נשאר עם הערך הקודם |
| הדבקה של "1,000" | **נדחית**: הפסיק הוא נקודה עשרונית, ו-"1.000" זה 3 ספרות אחריה. כך "אלף" אף פעם לא נקרא בטעות כ-1 |
| הדבקה של "1,000.50", ‏"‎-5", ‏"5 ₪", ‏"1e3" | נדחית |

- **הודעה אחרי דחייה:** מתחת לשדה, `footnote`, ‏`text.secondary` (לא אדום, זו לא שגיאה של המשתמש): "אפשר להזין רק מספר, עם עד 2 ספרות אחרי הנקודה." היא נעלמת בהקלדה החוקית הבאה. **[חובה]** גם ל-live region, ‏`polite`. בהקשה רגילה שנדחתה (ספרה שלישית אחרי הנקודה) **בלי הודעה**: השדה פשוט לא משתנה, כמו `maxLength`.
- **מימוש:** דוחים ב-`onChangeText` (משווים לערך הקודם), לא ב-`maxLength`. ‏`onChangeText` לא מבדיל בין הקלדה להדבקה, ולכן הכלל: שינוי של יותר מתו אחד שנדחה ← הודעה; תו אחד שנדחה ← בלי הודעה.

### 4.4 מקרי קצה

- **USD:** שני שדות בלבד (USD ו-₪). כותרת ושורה כמו בכרטיס.
- **בלי רשת:** **[חובה] עובד** עם השער השמור.
- **אין שער:** השורה לא לחיצה, ולכן המחשבון לא נפתח.
- **השער מתעדכן כשהגיליון פתוח:** **[חובה] לא מחליפים** את השער באמצע חישוב. המחשבון לוקח עותק של השער בפתיחה.

### 4.5 נגישות

- **פתיחה:** הפוקוס בשדה המקומי (כמו גיליון הנוסע). ההכרזה: "דונג וייטנאמי, סכום, 1000, תיבת עריכה".
- **סדר:** כותרת ← שורת השער ← שדה מקומי ← ₪ ← $ ← אחריות ← "עודכן ב-" ← ייחוס ← ×.
- **תווית שדה:** "{{name}}, סכום" ("שקל חדש, סכום"). לא "סכום ב{{name}}", כדי שלא ייווצר "בהאירו" (אותו כלל של ג'ון מספרינט 2, 19.8).
- **[חובה] הערכים המחושבים לא מוכרזים** בכל הקשה (זה רעש). מי שרוצה, עובר לשדה ושומע את הערך.
- **130%:** השדות ברוחב מלא, אז אין בעיה. הגיליון נגלל מעל המקלדת (`ScrollView` בתוך הגיליון, `keyboardShouldPersistTaps="handled"`).

### 5.2 איפה הוא מופיע

| מקום | איך | לחיץ? |
|---|---|---|
| **כרטיס המדינה** | מתחת לשם באנגלית, `marginTop: 8`. בגודל של 5.1, עם ‏`hitSlop` שמשלים ל-48 בגובה (התג 24 ‏+ 12 מכל צד) | **כן:** פותח את "כניסה ואזהרות מסע" (סעיף 7) בחלק של הכניסה |

## 6. אזהרת המל"ל בכרטיס (F-013: AC-7)

### 6.1 הסרגל (`AdvisoryBar`)

**ארבעה מקטעים, מצד ההתחלה** (בעברית מימין לשמאל, `flexDirection: row`, מתהפך לבד). מספר המקטעים המלאים = הרמה. **[חובה] תמיד עם מילים לידו**, והמקטעים הריקים עם קו מתאר, כך שהרמה ברורה גם בלי צבע (מספר המקטעים) וגם בלי ראייה (הטקסט).

| גודל | מקטע | רווח | פינה | שימוש |
|---|---|---|---|---|
| כרטיס | 12×8 | 3 | 2 | שורת האזהרה (57 רוחב) |
| גיליון | `flex: 1` × 8 | 4 | 2 | ברוחב מלא |
| שורת נסיעה | 8×6 | 2 | 1.5 | שורת המצב בשורה הפתוחה (38 רוחב) |

**צבע לפי הרמה. כל המקטעים המלאים בצבע של הרמה** (לא מדרג של ארבעה צבעים):

| רמה | בהיר | כהה | ניגוד מול `bg.surfaceRaised` (בהיר / כהה) |
|---|---|---|---|
| 1 | Lagoon 600 `#0B7F73` | Lagoon 300 `#4FCFBE` | 4.89 / 8.84 |
| 2 | Sand 600 `#8F7550` | Sand 400 `#D9BE90` | 4.35 / 9.41 |
| 3 | Sunset 600 `#C8441F` | Sunset 400 `#FF7A57` | 4.88 / 6.56 |
| 4 | Alert 600 `#C81E16` | Alert 400 `#FF5D52` | 5.75 / 5.57 |
| מקטע ריק | קו 1dp ב-`border.control` ‏`#7D869E`, בלי מילוי | קו `#7487BD` | 3.64 / 4.77 |

- **[חובה] כל הצבעים ≥ 3:1** (1.4.11) על `bg.surfaceRaised` ועל רקע השורה הפתוחה (סעיף 16.1).
- **למה לא ירוק-צהוב-כתום-אדום רגיל:** צהוב לא עומד ב-3:1 על לבן, ו"רמזור" מלא נראה מבהיל. Sand לרמה 2 הוא "שימו לב" שקט. Sunset לרמה 3 כבר מורגש. אדום רק ב-4 (הבקשה של יוסי: רגוע אבל ברור).

### 6.2 שורת האזהרה (`AdvisoryRow`)

```
 אזהרת מסע של המל"ל                              caption, text.secondary
 ▮▮▮▯  רמה 3 · איום בינוני                    ‹  Pressable, minHeight 48
 עודכן ב-24.10.2026 (ייתכן שלא מעודכן)            רק כשישן מ-30 יום
```

- **תווית:** "אזהרת מסע של המל"ל" (`caption`, ‏`text.secondary`).
- **השורה:** הסרגל, ‏`gap: 8`, הטקסט ב-`callout` (‏15/22), ובצד הסוף שברון 16 ב-`text.tertiary` (**מתהפך ב-RTL**: מצביע שמאלה בעברית). ‏`Pressable`, ‏`minHeight: 48`, מצב לחוץ כמו בשורת השער. **הלחיצה פותחת את "כניסה ואזהרות מסע"** בחלק של המל"ל.
- **הטקסט:** "רמה {{n}} · {{מילה}}". ברמה 1–3 ב-`text.primary`, ‏`bodyStrong` למספר. **ברמה 4 כל הטקסט ב-`text.alert`** (5.75 / 5.57), ‏500. זה המקום היחיד בכרטיס שבו טקסט אדום.

## 7. גיליון "כניסה ואזהרות מסע" (`TravelInfoSheet`, AC-6 עד AC-9)

**גיליון אחד לשני הנושאים**, עם שתי נקודות כניסה (התג ושורת האזהרה). כך יש רכיב אחד, ומי שרואה "אין כניסה" רואה באותו מקום גם את האזהרה.

### 7.1 המבנה

```
 ┌──────────────────────────────────────────┐
 │ כניסה ואזהרות מסע                     ×  │  title2
 │ תאילנד                                   │  callout, text.secondary
```

- **`BottomSheet`** עם `maxHeight` כמו "הנסיעות שלי" ו-`ScrollView` בפנים. נפתח מעל הכרטיס.
- **פתיחה מהתג:** הגיליון בגלילה 0. **פתיחה משורת האזהרה, כשיש גם חלק של כניסה:** גלילה לכותרת "אזהרת מסע של המל"ל". **[הצעה]** תמיד בגלילה 0 (פשוט יותר, והחלק של הכניסה קצר).
- **חלק הכניסה** (רק `restricted` / `banned`): התג בגודל של הכרטיס, הסבר קבוע לפי הסטטוס (סעיף 15.3), "נבדק ב-" (`verified_at` מהטבלה הידנית) וקישור "לפרטים במקור" למקור של השורה. **לא** מציגים הסבר ל-`allowed`.
- **חלק המל"ל:** סרגל גדול, "רמה {{n}} מתוך 4" (או "עד"), המילה וההמלצה, "הרמה משתנה לפי אזור. הפירוט בטקסט למטה." כשצריך, ותאריך. **"אין אזהרת מסע מפורסמת"**: בלי סרגל, הנוסח ו"נבדק ב-". **"בהשלמה"**: "עוד לא בדקנו את האזהרות לאזור הזה." ובלי טקסטים.
- **הטקסטים של כל גוף** (AC-8): כותרת `caption` ("המל"ל", "משרד החוץ", "משרד הבריאות") ואז הטקסט המלא ב-`body`, ‏`text.primary`. **רק גוף שיש לו טקסט מוצג.** עד 8 שורות ואז "עוד" (אותו רכיב של ההערות בשורה הפתוחה, ספרינט 2). **[חובה] הטקסט מוצג כמו שהוא**, בלי עיבוד, בלי הדגשת הרמה ובלי קיצור. רק מנרמלים רווחים ושורות ריקות כפולות.
- **[חובה] באנגלית:** הטקסטים נשארים בעברית (AC-8), עם `writingDirection: 'rtl'` ו-`textAlign: 'right'`, ומעל הראשון שבהם שורה ב-`footnote`: "Official text, available in Hebrew only." הכותרות, הרמה והמילים מתורגמות.
- **קישור רשמי:** כפתור משני (`action.secondary`) "לעמוד הרשמי ב-gov.il" עם אייקון "קישור חיצוני" (**לא מתהפך**), ‏`Linking.openURL` לקישור של השורה. בלי רשת הדפדפן מציג את השגיאה שלו, כמו ברישיונות בספרינט 3.
- **שורת האחריות (AC-9), [חובה] בכל מצב**, גם ב"בהשלמה", אחרונה בגיליון, נוסח מדויק.
- **בלי רשת:** הכול מהשמירה, חוץ מהקישורים.

### 7.2 נגישות

- **פתיחה:** הפוקוס על הכותרת. **סדר:** כותרת ← שם המדינה ← (כותרת כניסה ← תג ← הסבר ← נבדק ← קישור) ← כותרת המל"ל ← הרמה (קבוצה אחת: "עד רמה 4 מתוך 4, איום גבוה, להימנע מהגעה, הרמה משתנה לפי אזור") ← עודכן ← כל גוף (כותרת header, טקסט, "עוד") ← קישור רשמי ← אחריות ← ×.
- **הסרגל** מוסתר מקורא המסך: הרמה כבר בטקסט.
- **130%:** הכול בעמודה אחת וגולש. בלי חיתוך, חוץ מה-8 שורות עם "עוד".

## 8. השורה הפתוחה של נסיעה (AC-6, AC-7)

**שורת מצב אחת, ראשונה בשורה הפתוחה**, לפני "ערים":

```
 │ [⊘ אין כניסה]  ▮▮▯▯ אזהרת המל"ל: רמה 2       │  flexWrap, gap 4/8
 │ ערים                                       │
 │ ...                                        │
```

- **מה בה:** תג הכניסה (אם יש, סעיף 5.1, לא לחיץ) והסרגל הקטן (8×6) עם "אזהרת המל"ל: רמה 2" ב-`footnote`, ‏`text.secondary` (ברמה 4: ‏`text.alert`). כשיש כמה רמות: "אזהרת המל"ל: עד רמה 4". "אין אזהרת מסע מפורסמת" ו"בהשלמה" בלי סרגל, בנוסח המלא.
- **[חובה] היא לא לחיצה.** הפרטים נמצאים במרחק גלילה, בשורת האזהרה של אותו כרטיס. כך אין עוד יעד מגע בשורה שכבר יש בה שלושה כפתורים.
- **למה בכלל, אם זה אותו כרטיס:** AC-7 מבקש. ובמצב גלילה (1.3), כשהכרטיס נפתח על נסיעה, השורה הפתוחה היא מה שרואים קודם.
- **ישראל, ‏"בהשלמה" בלי תג כניסה:** **[חובה] אין שורת מצב בכלל** כשאין תג וגם המצב "בהשלמה": שורה שאומרת רק "בהשלמה" בכל נסיעה היא רעש.
- **נגישות:** פריט אחד: "אין כניסה בדרכון ישראלי, אזהרת המל"ל: רמה 2 מתוך 4, איום מזדמן". **סדר בשורה הפתוחה:** השורה ← **שורת המצב** ← ערים ← טמפרטורה ← הערות ← עריכה ← שכפול ← מחיקה.

## 9. ערים בחיפוש הראשי (F-014: AC-10, AC-11)

### 9.1 התוצאות


- **[חובה] קודם עד 8 מדינות, אחר כך עד 5 ערים** (AC-10), באותה רשימה ובאותו כרטיס של ספרינט 1.
- **כותרות קבוצה:** "מדינות" ו"ערים" (`caption`, ‏`text.tertiary`, ‏`paddingTop: 12`, ‏`paddingBottom: 4`, ‏`accessibilityRole="header"`). **[חובה] רק כששתי הקבוצות מוצגות.** כשיש רק מדינות, הרשימה נראית בדיוק כמו היום. כשיש רק ערים, בלי כותרת: הפסיק והמדינה בשורה מסבירים.
- **שורת עיר** (`minHeight: 56`, כמו שורת מדינה):
  - **שורה 1:** "בנגקוק" ב-`bodyStrong`, ‏`text.primary`, ואחריו ", תאילנד" ב-`body`, ‏`text.secondary` (כמו "(בריטניה)" בשטחים, אותו `Text` מקונן). המדינה היא שם התצוגה של האזור שהעיר שייכת לו (`displayName`, כולל שטחים).
  - **שורה 2:** השם באנגלית מ-GeoNames ב-`footnote`, ‏`text.secondary`, עם isolate. **עיר בלי שם עברי:** שורה 1 היא השם באנגלית עם isolate ו", תאילנד", ובלי שורה 2.
  - **בצד הסוף:** תג הכניסה של המדינה (אם יש) ותג הקוד של המדינה (`THA`). התג מאותו אזור, ולכן ברור לאן ההקשה מובילה.
  - **[חובה] בלי אייקון עיר.** הכותרת והפסיק מספיקים, ואייקון היה מזיז את היישור לעומת שורות המדינה.
- **"יש עוד תוצאות. המשיכו להקליד":** כמו היום, אחרון, כשאחת הקבוצות נחתכה.
- **מקש Enter במקלדת:** בוחר את התוצאה **הראשונה ברשימה** (מדינה, ואם אין, עיר), כמו היום.
- **אין תוצאות בכלל:** "לא נמצאו מדינות או ערים" ו"החיפוש לפי שם מדינה או עיר, בעברית או באנגלית." (עדכון לנוסח של ספרינט 1).

### 9.2 טעינה **[חובה]** (AC-11)

- **המדינות לא מחכות.** הן מוצגות בכל הקשה, כמו היום.
- **מתי מחפשים ערים:** **מ-2 תווים** (אחרי נרמול). בתו אחד יש אלפי ערים שמתחילות בו, ו-5 הגדולות שבהן הן רעש. בתו אחד הרשימה זהה להיום.
- **האינדקס עוד לא מוכן** (פתיחה ראשונה של החיפוש ב-session, והשאילתה ≥ 2): אחרי המדינות שורה אחת, `minHeight: 48`, לא לחיצה: ‏`ActivityIndicator` 16 ו"טוענים ערים…" ב-`footnote`, ‏`text.secondary`. **[חובה] היא מופיעה רק אחרי 150ms** (`motion.skeleton.delay`), כדי שלא תהבהב.
- **כשהאינדקס מוכן:** הערים מחליפות את השורה, ב-Fade של 150 (`standard`), בלי תזוזה של המדינות שמעל. **[חובה] המדינות לא זזות** אף פעם בגלל הערים, כי הן תמיד מעל.
- **האינדקס נכשל:** אין ערים ואין שורה. ביומן רק קוד (`city_index_failed`). החיפוש עובד כמו בספרינט 1.
- **מתי טוענים:** **[חובה] כשהחיפוש נפתח**, לא אחרי `globe-ready`, כדי לא להאט את הפתיחה. **[הצעה]** לטעון ב-`InteractionManager` אחרי `globe-ready` + 5 שניות, כדי שבפעם הראשונה כבר יהיה מוכן.
- **בלי רשת:** עובד. הקובץ ארוז באפליקציה.

### 9.3 בחירה בעיר (AC-11)

- **[חובה] בדיוק כמו בחירה במדינה שלה:** המקלדת נסגרת, החיפוש מתקפל, הגלובוס עף לאזור, הבחירה עולה והכרטיס נפתח. אותה קריאה ל-`onSelect(adm0)`.
- **הכרטיס לא משתנה** בגלל העיר: אותה שעה מקומית, אותה טמפרטורה. **[הצעה, סעיף 20]** להציג את השעה של העיר כשיש למדינה כמה אזורי זמן.
- **הכרזה:** הקיימת, "נבחרה: תאילנד". **[הצעה]** "נבחרה: תאילנד (בנגקוק)". לא חובה, כי הכרטיס הוא של תאילנד.

### 9.4 נגישות

- **שורת עיר:** `accessibilityRole="button"`, תווית "בנגקוק, תאילנד, Bangkok" ואם יש תג ", כניסה מוגבלת בדרכון ישראלי". ‏hint: "פותח את הכרטיס של תאילנד".
- **ספירה** (600ms אחרי ההקשה האחרונה, כמו היום, **ושוב אם הערים הגיעו אחרי ההכרזה**, אבל רק אם השאילתה לא השתנתה): "נמצאו: 1 מדינה, 5 ערים" (סעיף 15.4). כשיש עוד: "יש עוד תוצאות. המשיכו להקליד" בסוף.
- **130%:** תג הכניסה יורד מתחת לשם באנגלית, ותג הקוד נשאר בצד.

## 10. בלי רשת: קריאה בלבד (F-015: AC-13, AC-14)

### 10.1 מתי זה המצב

**"מצב שמור"** = אין רשת (NetInfo) **וגם** יש מטמון שה-`user_id` שלו זהה למשתמש המחובר (AC-13). **אותו מצב** גם כשהנתונים נטענו מהרשת, והרשת נפלה אחר כך (היום: `offlineStale`). הזמן שמוצג הוא הזמן שבו הנתונים נטענו מהשרת.

| | מצב שמור | אין רשת, אין מטמון |
|---|---|---|
| הקופון | שורות מהמטמון + הודעה (10.2) | "צריך חיבור כדי לראות את הנסיעות." (כמו היום) |
| "הנסיעות שלי" | רשימה מהמטמון + הודעה | "צריך חיבור כדי לראות את הנסיעות" (כמו היום) |
| הדגשה ופין | כמו עם רשת | כמו היום (אין) |

**כשהרשת חוזרת:** טעינה שקטה מהשרת, ההודעה נעלמת, הכפתורים חוזרים. **[חובה] בלי הכרזה ובלי Toast.** אם הנסיעה הפתוחה נמחקה בינתיים במכשיר אחר, השורה נסגרת ונעלמת בלי אנימציה.

### 10.2 ההודעה: "מוצג מהשמירה האחרונה · [תאריך]"

- **בקופון:** מתחת לכותרת "הנסיעות שלך", בסגנון שורת ה-offline הקיימת בקופון (`CloudOffIcon` 16 ב-`text.tertiary` ו-`footnote`, ‏`text.secondary`), **לא** `InlineNotice` מלא: בקופון אין מקום לקופסה של 48dp.
- **ב"הנסיעות שלי":** `InlineNotice` מתחת לכותרת, במקום ההודעה `offlineStale` הקיימת.
- **הנוסח:** "מוצג מהשמירה האחרונה · {{when}}":
  - היום: "היום, 14:32"
  - אתמול: "אתמול, 09:10"
  - לפני כן: "23.10.2026"
  - השעה ב-24 שעות, עם isolate. "היום" ו"אתמול" לפי התאריך המקומי.
- **[חובה] בלי "ייתכן שלא מעודכן"** כאן. "מוצג מהשמירה האחרונה" כבר אומר את זה, והתאריך מראה כמה ישן.

### 10.3 עריכה חסומה **[חובה]** (AC-14)

**במצב שמור, כל פעולה שכותבת חסומה:** "עריכה", "שכפול", "מחיקה" בשורה הפתוחה, ו"נסיעה חדשה" בקופון. **למה גם "נסיעה חדשה" ו"שכפול":** הם פותחים טופס שלא יישמר. "קריאה בלבד" אחיד קל להבנה יותר מ"חלק כן וחלק לא" (שאלה 7).

- **המראה:** הכפתורים בסגנון disabled הקיים (`action.disabled.bg/fg`, בכפתורי טקסט רק `action.disabled.fg`). "נסיעה חדשה" מאבד את ה-Sunset.
- **[חובה] הם עדיין מגיבים להקשה:** הקשה מציגה `InlineNotice` מתחת לכפתורים (בשורה הפתוחה) או מעל "נסיעה חדשה" (בקופון): "בלי חיבור אפשר רק לצפות. עריכה תחזור כשיהיה חיבור." ההודעה נשארת עד שהשורה נסגרת או שהרשת חוזרת. **למה לא `disabled` אמיתי:** כפתור אפור שלא עושה כלום לא מסביר למה. במצב לחץ בשדה תעופה, הקשה שמסבירה עדיפה.
- **מימוש:** בלי `disabled` של `Pressable`. ‏`accessibilityState={{ disabled: true }}` והקשה שמציגה את ההודעה.
- **החלפת מצב באמצע** (הרשת נפלה כשהטופס כבר פתוח): הטופס מתנהג כמו היום ("כדי לשמור נסיעה צריך חיבור. מה שמילאת נשאר כאן."). החסימה היא רק בכניסה.

### 10.4 בלי "טען עוד" **[חובה]**

- **במצב שמור** לא מבקשים עמוד נוסף: `onEndReached` ו-`loadMore` לא פועלים, ואין ספינר ואין "לא הצלחנו לטעון עוד נסיעות".
- **אם המטמון התמלא** (50 קרובות או 20 שעברו, AC-12), בסוף הרשימה שורה ב-`footnote`, ‏`text.tertiary`: "נסיעות נוספות יוצגו כשיהיה חיבור." כך לא נראה שנסיעות נמחקו. בקופון של מדינה, השורה מוצגת רק אם המטמון של המשתמש מלא (אי אפשר לדעת לכל מדינה).

### 10.5 מסכים נוספים (AC-13)

- **מחיקת חשבון, "מה נמחק מיד":** הנוסח `deleteAccount.deletedDevice` מתעדכן (סעיף 15.6).
- **התנתקות:** בלי שינוי בממשק. המטמון נמחק לפני שהממשק מתעדכן, כמו ההדגשה בספרינט 2.
- **מדיניות הפרטיות:** טיוטה של ג'ון, לא אני. הנקודה: "עותק מוצפן של הנסיעות נשמר במכשיר כדי להציג אותן בלי רשת, ונמחק בהתנתקות ובמחיקת החשבון."

### 10.6 נגישות

- **ההודעה** ב-live region, ‏`polite`, **פעם אחת** כשהמצב נכנס. לא בכל פתיחה של שורה.
- **כפתור חסום:** TalkBack אומר "עריכה, לא זמין". ‏hint: "בלי חיבור אפשר רק לצפות". אחרי הקשה, ההודעה מוכרזת.

## 17. הערות למימוש (לרז ולדורי)

1. **מקור אחד לשער ולאזהרה במכשיר:** טעינה של כל השערים (התצוגה "השער האחרון") ושל כל האזהרות **פעם אחת** אחרי `globe-ready`, ושמירה ב-AsyncStorage (לא מוצפן, AC-4; גם האזהרות הן לא מידע אישי). הכרטיס קורא מהזיכרון. רענון: בפתיחה, וכשהאפליקציה חוזרת לחזית אחרי יותר מ-6 שעות. **בלי שאילתה לכל כרטיס.**
2. **`formatRateLine`** ובדיקות היחידה של 3.4. ‏`isolateLtr` הקיימת.
3. **"ישן":** ‏`Date.now() - fetched_at > 3 × 86400000` (שער), ‏`> 30 × 86400000` (אזהרה), לפי שעון המכשיר, בכל רינדור של הכרטיס (בלי טיימר).
4. **הרמה המעורבת:** צריך `nsc_level_min` או מערך (שאלה 1). בלי זה, אין "עד".
5. **מצב גלילה (1.3):** החישוב כבר קיים (`maxListHeight` ב-`BoardingPassCard`). כשהוא קטן מ-`size.tripRow.min`, עוטפים ב-`ScrollView` ומעבירים ל-`coupon` את `Infinity`. ה-SVG של הרקע עובר לתוך התוכן. הגלילה לשורה הפתוחה עוברת ל-ScrollView החיצוני.
6. **המחשבון:** state אחד `{ source: 'local'|'ils'|'usd', text }`, ושני השדות האחרים נגזרים ממנו בכל רינדור. כך אין לולאה של עדכונים ואין שגיאת עיגול מצטברת.
7. **חיפוש ערים:** האינדקס הגלובלי נבנה כשהחיפוש נפתח לראשונה. `searchCities(query, 5)` רק מ-2 תווים, אחרי `searchCountries`. סינון של אזורים שאינם ניתנים לבחירה (AC-10) באינדקס, לא בכל שאילתה. מודדים את ה-300ms מההקשה לפריים, עם `logSearchResults` הקיים.
8. **מצב שמור:** דגל אחד ב-`TripsProvider` (`source: 'server' | 'cache'`, ‏`loadedAt`), שהקופון, "הנסיעות שלי" והכפתורים קוראים ממנו. הוא מחליף את `offlineStale`.
9. **כפתור חסום:** הרחבה קטנה ל-`Button` הקיים: `blocked?: string` (טקסט ההודעה). כשהוא מוגדר: מראה disabled, ‏`accessibilityState.disabled`, והקשה קוראת ל-`onBlockedPress`.
10. **קישורים:** `Linking.openURL` בלבד, כמו בספרינט 3. אין `expo-web-browser`.
11. **אין תלות חדשה.**

## 19. שאלות פתוחות (לרז ולג'ון)

1. **רמה מעורבת (AC-8):** נשמרת רק "הרמה הגבוהה". כדי להציג "עד רמה 4 · הרמה משתנה לפי אזור" צריך גם את הנמוכה (`nsc_level_min`) או את כל הרמות שזוהו. **המלצה:** להוסיף עמודה `nsc_levels smallint[]` באותה משיכה. בלי זה, תאילנד מוצגת כ"רמה 4" בלי הסתייגות.
2. **"אין אזהרת מסע מפורסמת" מול "בהשלמה":** מה קובע? ההנחה שלי: יש שורה במאגר בלי רמה בטקסט של המל"ל ← "אין אזהרה מפורסמת"; אין שורה בכלל (כולל שטחים) ← "בהשלמה". צריך להגדיר את זה באפיון, כי זה ההבדל בין "בדקנו ואין" לבין "לא בדקנו".
3. **הדוגמה ב-AC-1** ("0.04 $") סותרת את כלל 2 הספרות ("0.038 $"). הלכתי לפי הכלל. מבקשת שג'ון יתקן את הדוגמה באפיון.
4. **תאריך העדכון של האזהרה:** אני מציגה את `fetched_at`. אם במאגר יש תאריך פרסום של gov.il, הוא מדויק יותר ל"עודכן ב-", ו-`fetched_at` מתאים ל"נבדק ב-". שווה לבדוק כשבודקים את המאגר.
5. **התאריך של האזהרה בכרטיס:** הצגתי אותו רק כשהוא ישן, והוא תמיד מופיע בגיליון. אם רז קורא את AC-7 כ"תאריך בכרטיס עצמו", מוסיפים 18dp.
6. **אדום ל"אין כניסה":** מערכת העיצוב (1.3) שומרת Alert לשינוי טיסה, חירום ו-SOS. מבקשת אישור להוסיף "אין כניסה" ורמה 4.
7. **"נסיעה חדשה" ו"שכפול" בלי רשת:** AC-14 אומר "עריכה". חסמתי גם אותם, כדי ש"קריאה בלבד" יהיה אחיד. אם ג'ון מעדיף לאפשר לפתוח טופס שלא יישמר (כמו היום), זה שינוי של שורה.
8. **"הנסיעות שלי" ותג כניסה:** AC-6 מונה רק את החיפוש, הכרטיס והשורה הפתוחה. השארתי את הרשימה בלי תג.
9. **ILS מחוץ לישראל:** אזור שהמטבע שלו ILS ואינו `ISR` (למשל השטחים הפלסטיניים) מקבל את הכלל של AC-1א: אין שורת שער. האזהרה ותג הכניסה שלו מוצגים כרגיל, לפי הנתונים. כדאי שג'ון יוודא שזו הכוונה.
10. **רישיון data.gov.il:** אם הוא דורש נוסח ייחוס מסוים, הוא נכנס לגיליון "מקורות" ואולי גם לגיליון האזהרות. ג'ון בודק לפני הפיתוח (AC-8).
