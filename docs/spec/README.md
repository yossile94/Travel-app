## פורמט פיצ'ר חדש

פיצ'רים חדשים, ופיצ'רים קיימים כשהם נכנסים לספרינט, מקבלים מזהה ייחודי (למשל `F-012`) וקריטריוני קבלה שאפשר לבדוק:

```markdown
### F-012: <שם הפיצ'ר>

**סיפור משתמש:** בתור <משתמש>, אני רוצה <יכולת>, כדי ש<ערך>.

**קריטריוני קבלה:**
- [ ] AC-1: בהינתן <מצב>, כאשר <פעולה>, אז <תוצאה>.
- [ ] AC-2: ...

**פרטיות ורגולציה:** אילו נתונים נאספים, מי רואה אותם ולכמה זמן הם נשמרים.

**מחוץ לתכולה:** ...
```
