# 7. צד אדמין

פאנל Web (Next.js) לצוות התוכן והתפעול – מנהל את הידע הגלובלי (מדינות, קונסוליות, המלצות), לא את הנסיעות הפרטיות של המשתמשים. הגישה מוגבלת ל-MFA, ולכל פעולה נרשם Audit Log.

| מודול | יכולות | תפקיד מורשה |
|---|---|---|
| מדינות | שם בעברית/אנגלית/מקומית, aliases לחיפוש, שפות רשמיות, מטבע, מספרי חירום מקומיים, סטטוס כניסה לבעלי דרכון ישראלי, רמת אזהרת מסע של המל"ל ותור אישור לשינויים | Content Editor |
| נציגויות ישראל | כתובת, טלפונים, שעות, מיקום, מדינות שבאחריות, מקור ו"אומת לאחרונה"; התראה על שורות שלא אומתו 90 יום | Content Editor |
| המלצות אוצרות | יצירה ועריכה, קטגוריות, תמונות, שיוך לעיר/מדינה, פרסום/טיוטה | Content Editor |
| משתמשים | חיפוש לפי מייל או מזהה משתמש, סטטוס חשבון, השעיה, טיפול בבקשות פרטיות (מחיקה, ייצוא). **ללא** גישה לתוכן נסיעות | Support (מוגבל) |
| מסמכים משפטיים | גרסאות של תנאי שימוש ומדיניות, הגדרת "שינוי מהותי" שמחייב הסכמה מחדש, דוח הסכמות | Admin |
| Flight Watch | בריאות הספק, כמות קריאות ועלות, שגיאות, טיסות במעקב | Admin / Dev |
| התראות | שליחת Push מערכתי מסונן לפי מדינת יעד (למשל אזהרת מסע) | Admin |
| מודרציה (שלב קהילה) | דיווחים, הסרת תוכן, חסימת משתמשים | Moderator |
| דשבורד | משתמשים פעילים, נסיעות פעילות לפי מדינה, מדדי פרק 1 | כולם |

**הרשאות:** RBAC עם 4 תפקידים (Admin, Content Editor, Support, Moderator), מאוחסן בטבלה `admin_roles` ונאכף ב-RLS דרך `has_role()`, שבודקת גם AAL2 – לא רק ב-UI. לא משתמשים ב-custom claims: תפקיד שהוסר נחסם מיד (ספרינט 10, ADR-015). עקרון הרשאה מינימלית.
